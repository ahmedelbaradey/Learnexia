## Decisions (lead, 2026-06-22)
- **Regression scope = golden journey + coverage inventory.** Build ONE new cross-story end-to-end "golden path" integration test + a doc inventorying the existing ~95 per-story integration tests mapped to the critical journeys + the single run command; run the full integration suite and record the result. (Not a doc-only checklist, not the broad multi-variant suite.)
- **AC2 prompt-tuning / AI output quality = DEVOPS-GATED.** Judging real Claude/OpenAI explanation/question quality needs live keys + human review — the same gate as P6-02 Gate-B / flip-to-live. This story **documents** the sample + quality-bar procedure; the actual run is devops (no keys here).

## Current state (verified 2026-06-22)
- Large existing test corpus: **~95 integration test files** (`backend/tests/Learnexia.IntegrationTests`, per-story P1–P10) + 7 module unit-test projects + `Ai.EvalTests` + `Learnexia.PerfTests`. **No single cross-story golden-journey test** exists (the closest E2E specs are feature-scoped: `P3_AI_RuntimeActivation_E2E`, `P10_W2_EnergyEconomy_E2E`).
- Reuse the `LearnexiaWebAppFactory` (Testcontainers PG) + the register-parent→add-child→sign-in→start-attempt flow proven in `P2_06_StartAttempt_Tests`.
