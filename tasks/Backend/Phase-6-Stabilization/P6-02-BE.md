## Context (grounded by the analyzer)
- Safety checks are **mixed**: `ToxicityCheck` + `AgeAppropriatenessCheck` are **LLM-backed** (`IAiGateway`, keys devops-gated); `HallucinationCheck` is **deterministic**. Composed in `Ai.Application/Safety/SafetyLayer.cs` (input-screen → gateway → concurrent checks → Block / NeedsRegeneration / Allow → `SafetyEvent`).
- "Unsafe" spans BOTH `Block` (high severity) and `NeedsRegeneration` (medium/borderline) — eval cases assert the expected OUTCOME, not a single state.
- Groundwork exists: `backend/tests/Ai.EvalTests/Data/safety-eval-set.json` (~20 cases) + `SafetyEvalHarnessTests.cs`. Gaps: subject-blind; the no-key gateway always fails so LLM-check "safe" cases can't pass → need the deterministic fake.
