## Context (verified 2026-06-22)
- The grade-change **plumbing already exists** for the ADMIN path: `Identity/.../OverrideChildGrade/OverrideChildGradeCommand(Handler)` (admin sets a child's grade) → publishes `Shared.Contracts.Identity.ChildGradeChangedIntegrationEvent` → `Learning/.../ChildGradeChangedIntegrationEventHandler` **re-scopes the child's learning** to the new grade. History is naturally preserved (grade is a field on the User; XP/badges/streaks/mastery live in Gamification/Learning keyed by userId, untouched by a grade change).
- **What's missing (this story):** a **PARENT-initiated** transition — a parent-scoped endpoint (parent dashboard control, P5-05) with **parent→child IDOR auth** (`IsParentOfChildAsync`/`IChildAccountService`), grade 1–6 validation, and an audit record. The admin path is admin-only; parents cannot transition their own child today.
