> Phase 5 · Module: **Learning** (mastery is the source) · exposed to parents via the `Ai.IStudentWeakAreasQuery` seam re-wire in P5-08

## Design rules (binding)
- Reuse existing mastery signals — do NOT invent a new model. The `<50%` = `NeedsReview` mastery state on `StudentSkillMastery` already encodes the weak-area bar (analyzer finding). Detection = rank a child's skills/subjects by mastery deficit + recent error rate.
- Module isolation, Option C (logic behind a service/query, Application EF-free), `ILoggerManager`, localized output, loose `int` ids over any seam.
