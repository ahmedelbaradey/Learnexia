## Acceptance-criteria coverage
- Parent adds child + sets grade/lang/country → **BE-2, BE-3**
- Multiple children → **BE-5**
- Provisions child account w/ assigned login email → **BE-2, BE-7**
- Child cannot self-onboard → enforced by parent-only endpoint + P1-01-BE-5
- Invalid grade / duplicate email rejected → **BE-6**
- Child language sets locale on first login → **BE-3** (exposed via P1-09-BE-1)

## Contract for Frontend (P1-03-FE)
- Add-Child accepts `{ childName, loginEmail, grade(1-6), language(ar|en), country }`; returns the created child profile. Multiple calls (or a batch array) supported.
