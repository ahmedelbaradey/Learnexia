## Contract to Frontend (P1-11-FE / P2-12-FE)
- Profile DTO (fullName/phone/country/avatarUrl); enriched `Me`; upload result (avatarUrl); OAuth → JWT/refresh (same shape as `useSignIn`); reset request + set-new results. All `BaseResponse<T>` camelCase, `Successed`, `NewResult(...)`.
