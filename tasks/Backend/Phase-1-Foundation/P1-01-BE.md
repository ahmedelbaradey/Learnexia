## Acceptance-criteria coverage
- Parent registers → account + JWT → **BE-1, BE-4**
- Child not self-registered → **BE-5**
- Duplicate email rejected → **BE-3**
- Weak password blocked → **BE-3**
- Passwords hashed, never returned → ASP.NET Identity hashing + DTO omits password → **BE-1**

## Contract for Frontend (P1-01-FE)
- Register returns `BaseResponse<JwtAuthResponse>` (access + refresh token). Errors surface in `errors[]` with codes for duplicate-email / weak-password.
