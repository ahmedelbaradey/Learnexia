## Acceptance-criteria coverage

- Parent views current plan + status → **BE-4** (`GetCurrentPlanQuery`)
- Parent compares Free vs Premium benefits (config-driven, never hard-coded) → **BE-4** (`GetPlanComparisonQuery`)
- Upgrade transitions to `PendingPayment` (not `Active` until P9-06 payment) → **BE-5** (`RequestUpgradeCommand`)
- Downgrade takes effect at next cycle → **BE-5** (`RequestDowngradeCommand`)
- Active plan drives monthly grant → **BE-7** (`Shared.Contracts` seam for P9-02)
- Family plan: one subscription per parent, applies to all children → **BE-3** (filtered unique index) + **BE-5**
- Owning-parent-only access → **BE-6** + **BE-5** (family-scope authz)
- EN+AR renders → frontend story (P9-05-FE)
