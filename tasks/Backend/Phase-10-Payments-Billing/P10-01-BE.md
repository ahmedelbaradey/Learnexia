## Acceptance-criteria coverage

- One `CreditAccount` per child, `GrantedBalance` + `PurchasedBalance`, `TotalBalance` derived → **BE-2**
- Every balance change = append-only `CreditTransaction` with Type/Pool/Amount/Reason/ResultingBalances/OccurredAtUtc/IdempotencyKey → **BE-3, BE-5, BE-6**
- `account.balance == sum(ledger)`; reconciliation flags drift → **BE-7**
- DB unique constraint on idempotency key rejects duplicate → **BE-4** (constraint) + **BE-5** (catch/translate)
- `DebitAsync` draws Granted-before-Purchased, atomically, no over-draw under concurrency → **BE-5**
- Handlers return `BaseResponse<T>` (`Successed`); `ILoggerManager`; no UoW; module isolation; child as loose int ref → **BE-5, BE-6, BE-7, BE-9**
- `ICreditSpendService` seam for P10-03's cross-module consume → **BE-8**
