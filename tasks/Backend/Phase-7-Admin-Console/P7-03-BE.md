## Contract for Frontend (P7-03-FE)
- `GET /api/Learning/Skills/Graph?subjectId=` → `BaseResponse<SkillGraphDto>` (nodes[], edges[] with source/target/type/strength).
- `GET /api/Learning/Skills/{id}/Prerequisites` and `.../UnlockedBy` → `BaseResponse<List<SkillDto>>`.
- `POST/PUT/DELETE /api/Learning/Skills` → `BaseResponse<Guid>` / `BaseResponse<bool>`.
- `POST /api/Learning/Skills/Edges` (source, target, type, strength) → `BaseResponse<Guid>`; `DELETE .../Edges/{id}` → `BaseResponse<bool>`. Cycle → `Successed=false` with message. All admin-only.
