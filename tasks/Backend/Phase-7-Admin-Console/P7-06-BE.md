## Contract for Frontend (P7-06-FE)
- `GET /api/Admin/Users?role=&status=&q=&page=&pageSize=` → `BaseResponse<PagedResult<AdminUserListItemDto>>`.
- `GET /api/Admin/Users/{id}` → `BaseResponse<AdminUserProfileDto>`.
- `GET /api/Admin/Users/{id}/family` → `BaseResponse<FamilyDto>` (children[] for parent, parents[] for child).
- `GET /api/Admin/Users/{id}/activity` → `BaseResponse<ActivitySummaryDto>`. All gated by the admin policy; `Successed` flag per envelope.

## Notes
- Reuses the **Identity** module; list queries are paginated (per conventions). Activity crosses modules → consumed via `Shared.Contracts` integration seams only, never direct FK. Queries are not auto-validated (ValidationBehavior is `ICommand<>` only) — validate paging/filter inputs in the handler.
