## Acceptance-criteria coverage
- Lesson CRUD with metadata scoped to unit → **BE-1**
- Add content blocks with type/payload/order → **BE-2, BE-3**
- Reorder/remove blocks persists → **BE-3, BE-4**

- Admin-only access → **BE-1** (policy across controllers)

## Contract for Frontend (P7-02-FE)
- `GET /api/Learning/Units/{unitId}/Lessons` → `BaseResponse<List<LessonDto>>` (id, title, difficulty, estimatedMinutes, sequenceOrder, isLocked).
- `GET /api/Learning/Lessons/{id}/ContentBlocks` → `BaseResponse<List<ContentBlockDto>>` (id, type, payload, sequenceOrder).
- `POST/PUT/DELETE /api/Learning/Lessons` and `.../ContentBlocks` → `BaseResponse<Guid>` / `BaseResponse<bool>`.
- `PUT /api/Learning/Lessons/{id}/ContentBlocks/Reorder` and `.../Units/{id}/Lessons/Reorder` → `BaseResponse<bool>`. All admin-only.

## Notes
- `ContentBlock` is an additive child of `Lesson` in `learning`. `Payload` stored as jsonb (Npgsql). Reorder/delete-with-children use an explicit transaction (no Unit of Work).
- Mirror Catalog; `Successed`, `NewResult(...)`, `ILoggerManager`.
