> Story: [../../../user-stories/Phase-7-Admin-Console/P7-02-manage-lessons-and-content.md](../../../user-stories/Phase-7-Admin-Console/P7-02-manage-lessons-and-content.md)
> Phase 7 — Admin Console · Epic: Admin — Curriculum Management · SP: 8 · SRS §3, FR-ADM-1 · Est. unit: hours
> Stack: .NET 10 `Learning` module, CQRS/MediatR, FluentValidation, Npgsql.

> **Reality check (harden + extend, not greenfield):** Existing Learning `LessonsController` already exposes `Create` / `Update` / `Delete` endpoints, but they are currently **anonymous (live auth hole — see `docs/briefs/phase-7-admin-gap-analysis.md`)**. Lesson metadata (difficulty/estimatedTime/sequenceOrder/lockState) and content blocks are missing. This story = add `[Authorize(AdminOnly)]` on the existing Lesson endpoints + add ContentBlock + reorder; **NOT greenfield.**

## Contract for Frontend (P7-02-FE)
- `GET /api/Learning/Units/{unitId}/Lessons` → `BaseResponse<List<LessonDto>>` (id, title, difficulty, estimatedMinutes, sequenceOrder, isLocked).
- `GET /api/Learning/Lessons/{id}/ContentBlocks` → `BaseResponse<List<ContentBlockDto>>` (id, type, payload, sequenceOrder).
- `POST/PUT/DELETE /api/Learning/Lessons` and `.../ContentBlocks` → `BaseResponse<Guid>` / `BaseResponse<bool>`.
- `PUT /api/Learning/Lessons/{id}/ContentBlocks/Reorder` and `.../Units/{id}/Lessons/Reorder` → `BaseResponse<bool>`. All admin-only.

## Notes
- `ContentBlock` is an additive child of `Lesson` in `Learning`. `Payload` stored as jsonb (Npgsql). Reorder/delete-with-children use an explicit transaction (no Unit of Work).
- Mirror **Learning**; `Successed`, `NewResult(...)`, `ILoggerManager`.
- **Storage:** content-block media (image/video/file payloads) goes through `Shared.Kernel.Storage.IStorageService` (the shared storage seam introduced in P1-12 BE-4). Do not register MinIO module-locally.
- **Module isolation:** no cross-module FK; any cross-module data flows via `Shared.Contracts` only.
- **Policy:** `AuthorizationPolicies.AdminOnly` for now; promoting to granular `{Module}.{Action}` policies (via `Claims.GenerateModules()`) is a follow-up if the lead wants finer-grained authz.
