## Context (verified 2026-06-22)
- **Today:** `NudgeDispatcher.PublishSuppressedAsync` publishes `Shared.Contracts.Notifications.NotificationSuppressedIntegrationEvent` **only** on the P9-07 arbiter push-deny branch (`!result.ShouldPush` → reasons `GlobalBudgetExhausted` / `Cooldown` / `PriorityLost`). Consumed by `Analytics/.../NotificationSuppressedEventHandler` → `ActivityEvent` (`SuppressionReason` facet, P9-11) → surfaced by `GET /api/Admin/Analytics/notifications`.
- **Uncaptured suppression paths (the gap):**
  1. **Push pref OFF** — handlers pass `ShouldPush = prefs.Push`; `NudgeDispatcher` only enters the push gate `if (message.ShouldPush)`, so pref-off pushes never reach the arbiter → **no event**.
  2. **No active device tokens** — even with `ShouldPush=true`, a recipient with zero `UserDeviceToken`s gets no push → currently not recorded as a suppression.
  3. **Dedupe** — `ReengagementDedupeStore` short-circuits a nudge in the handler **before** `NudgeDispatcher` runs → no dispatch, no event.
