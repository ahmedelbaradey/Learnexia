# P3-01 (Backend) — Route AI requests through an AI Gateway

> Story: [../../../user-stories/Phase-4-AI-Tutor/P3-01-ai-gateway.md](../../../user-stories/Phase-4-AI-Tutor/P3-01-ai-gateway.md)
> Phase 4 — AI Tutor · Epic: AI Gateway · SP: 5 · NFR-2, NFR-9, NFR-1, NFR-4, NFR-8, FR-AI-6 · Est. unit: hours
> **Backend/infra only — no Frontend tasks.** Technical Enabler. First brick of the AI-Tutor cluster; all P3-02..P3-13 depend on it.
>
> **Locked decisions (from lead — do not re-raise):**
> - **Q1:** In-process .NET gateway (no Python/FastAPI service).
> - **Q2:** New `Ai` module (four-layer, mirrors Learning/Gamification). `IAiGateway` + DTOs in `Shared.Contracts/Ai/`. Provider SDKs isolated in `Ai.Infrastructure`.
> - **Q3:** Provider-abstraction pattern approved: `IAiProvider` adapters + `AiModelRouter` (Strategy/adapter registry).
> - **Q4 (REVISED):** Runtime default is CHEAP — NOT Opus. `CheckAnswer`/`Classify`/`ShortTask` → `claude-haiku-4-5`; `Explain`/`Hint`/`Simplify` → `claude-sonnet-4-6` (tutoring quality floor); `AnalyzeDiagram`/`HardReasoning`/`ContentQA` → `claude-opus-4-8` (offline/rare). The prior "default = Opus" wording is superseded by the approved cost-routing strategy (`docs/briefs/ai-cost-routing.md`). Always verify current Anthropic model IDs before launch.
> - **Q5:** Usage — **log-only** for P3-01; persist `ai.AiUsageLogs` table deferred to P7-11.
> - **Q6:** Streaming method signature defined now (`IAsyncEnumerable<AiChunk> StreamAsync`), streaming SSE endpoint deferred to P3-04. No debug HTTP endpoint — P3-01 is endpoint-less.
> - **Q7:** Provider client — thin typed `HttpClient` wrapper via `IHttpClientFactory` (no official SDK bloat).
>
> **Cost-routing strategy:** see `docs/briefs/ai-cost-routing.md` — the authoritative document governing model selection, prompt caching, Batch API, per-plan quotas, and graceful degradation. Tasks BE-10 through BE-14 below implement the P3-01-owned pieces of that strategy.

## Notes

- **Build order constraint:** P3-01 is the hard prerequisite for P3-02 and P3-03. `IAiGateway` + DTOs (BE-1) must be frozen before P3-02/P3-03 design can proceed to wiring.
- **Serialized shared-file edits:** `Learnexia.Modular.sln` (BE-2), `Directory.Packages.props` (BE-8), `Program.cs` (BE-9) — do NOT edit these concurrently with any other story per `docs/dev/PARALLELISM.md`.
- **No db-migration for core gateway:** gateway is stateless; `ai.AiUsageLogs` table deferred to P7-11. The `IAiUsageBudget` adapter (BE-14) writes to a plan/subscription column — confirm which migration owns that column (may be an additive column on an existing plan table, not a new migration here).
- **No HTTP endpoint:** P3-01 ships no controller; api-tester not required. Coverage = unit tests (BE-4/BE-10 router) + architecture test (BE-9).
- **Security-auditor gate is mandatory** before reviewer — secrets, outbound LLM calls, no-error-leak, bounded retries, quota bypass check.
- **Pattern approved:** `IAiProvider` adapter + `AiModelRouter` (Strategy/registry) are the literal subject of the story; they are pre-approved per the locked decisions above (rule 8 satisfied).
- **FR-AI-6:** the gateway returns *content* types only; it never returns a progression/unlock decision. This is an invariant the reviewer checks.
- Inject `ILoggerManager` not `ILogger<T>` (CLAUDE.md rule 5).
- `BaseResponse<T>` + `BaseResponseHandler` + `Successed` naming (rules 2, 3) apply to any MediatR handler introduced; the gateway facade itself returns `AiResult` (a typed discriminated result), not `BaseResponse<T>`, since it is below the MediatR layer.
- Always verify current Anthropic pricing/model IDs before launch — do not hardcode pricing as fact.
- **Cross-reference:** `docs/briefs/ai-cost-routing.md` is the governing strategy document for all model-routing, caching, and quota decisions in this task file.
