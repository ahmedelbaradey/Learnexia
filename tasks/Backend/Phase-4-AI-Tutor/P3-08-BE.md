## Notes

- **Depends on P3-09 merged.** Do not start BE-4 until `StudentSkillMastery` table and `IMasteryService`/repo seam exist.
- **No db-migration:** engine computes on demand from existing P2-08 + P3-09 signals. No new table.
- **Pattern caution (rule 8):** plain static engine + enum + config options object. No Strategy/State pattern. If the implementer reaches for one, stop and ask the lead first. This is the most tempting place in the cluster for a Strategy abstraction — the default is a plain function.
- **Time normalization degradation:** if `Skill.EstimatedTimeMinutes` or a student baseline is unavailable, weight time at 0 for that call and rely on accuracy+hints. Document this in the engine XML doc.
- **P3-13 optional feed-in:** `AdaptivityService` may receive a `FatigueSignal` from P3-13 when built; add a nullable parameter stub now so P3-13 can wire it without changing the method signature.
- **P3-06 consumer (AI module) not yet built:** AC4 is satisfied by the in-process seam + P3-11 consuming it. P3-06 wiring is deferred; note in HANDOFF.
- **Shared-file edits (serialize):** `SharedResourcesKey.cs`, `*.resx`, Learning DI extension. Confirm no concurrent story is editing these.
