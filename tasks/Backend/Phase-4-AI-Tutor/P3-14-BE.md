## Design rules (binding)
- **Reuse the Explain orchestration end-to-end** — do NOT invent a new path. New `HelperIntent.Recommendation` flows through: rate-limit → child-access gate → energy **pre-auth** (`ICreditSpendService.GetBalanceAsync`) → cache → `ISafetyLayer` → **`TryDebitAsync` on delivery**. Cost server-resolved via `CreditCostResolver.ResolveCost(HelperIntent.Recommendation)`.
- **Grounding:** narrate ONLY the child's persisted recommendation set from `IStudentRecommendationsQuery` (P5-09). NEVER recompute or invent recommendations. Tune tone/scope to the child's **Grade**; gamification level → motivational framing only.
- **Lead-approved (rule #8):** the 5th `HelperIntent` is approved; cost = **5**; **charge-per-delivery** (cache hit also charges). Module isolation, `ILoggerManager`, EN+AR, no further new pattern without asking.
