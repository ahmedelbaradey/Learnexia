> **Backend/infra only — no Frontend tasks.** Story. Most safety-critical story in the AI phase. Hard-depends on P3-01.
>
> **Locked decisions (from lead — do not re-raise):**
> - **Q1 (inherited):** In-process .NET `Ai` module (from P3-01). Safety Layer lives in `Ai.Application` / `Ai.Domain`.
> - **Q2 (moderation implementation):** Hybrid approach — fast moderation endpoint (Anthropic/OpenAI moderation API) for toxicity + age-appropriateness; cheap-tier LLM-as-judge via `IAiGateway` cheap route for nuanced cases. All behind `ICheck` interfaces.
> - **Q3 (pattern):** Facade approved — `ISafetyLayer.GenerateSafeAsync(AiRequest, CT)` owns the `IAiGateway` call + screening. This makes AC1 (no-bypass) structurally enforceable. Feature handlers call `ISafetyLayer`, never `IAiGateway` directly.
> - **Q4 (hallucination + input screening):** P3-03 owns prompt-construction hardening (fixed system frame). Safety Layer adds a light input screen for overtly unsafe student input. Hallucination check ships as a lighter heuristic now; tightened when P3-07 (RAG) lands.
> - **Q5 (quarantine):** Store reason-code + hash by default; no raw unsafe text in `SafetyEvents`. Access-controlled quarantine store deferred to P7-09 if human reviewers need the body.
> - **Q6 (persistence):** Persist a minimal, PII-light `ai.SafetyEvents` table now (P7-09 + P7-11 genuinely need queryable rows). No raw content body.
> - **Q7 (check composition):** Run all enabled checks concurrently (collect all reason codes) for richer logging; short-circuit on `Block` only if latency budget forces it.
> - **Q8 (streaming safety):** Buffer-and-screen in safe-sized chunks for streamed output (P3-04 concern); finalize with P3-04.

## Notes

- **Hard dependency on P3-01:** P3-01 must be merged (or at minimum `IAiGateway` contract frozen on a shared branch) before P3-02 wiring starts. Design of checks (BE-2..5) can proceed in parallel against the P3-01 contracts.
- **db-migration required:** `ai.SafetyEvents` table (BE-7) — additive, no cross-module FK, no raw content. Apply manually per CONVENTIONS §13 before integration tests run.
- **No HTTP endpoint:** safety layer is internal; api-tester not required. Coverage = eval-set harness (BE-9) + architecture test (BE-10) + unit tests in BE-6.
- **Security-auditor gate is mandatory** (highest priority in the cluster) — no-bypass, fail-closed, no unsafe-content leak, moderation secrets, log PII minimization.
- **Arabic-language safety quality risk:** many moderation models are weaker in Arabic. The eval set (BE-9) must include Arabic-language toxic samples. If the chosen moderation provider has weak Arabic coverage, flag as a quality risk and consider a secondary Arabic-specific classifier.
- **Fail-closed invariant:** on any check error, timeout, or unexpected exception the pipeline MUST block + fallback. A fail-open path is a Critical finding in security-auditor.
- **Streaming-safety contract (Q8):** deferred to P3-04. P3-02 ships non-streaming safety pipeline; P3-04 defines chunk buffering.
- **Regeneration is bounded:** `MaxRegenerationAttempts` from `SafetyOptions` (recommend default = 2). No infinite regen loop.
- `ILoggerManager` not `ILogger<T>` (rule 5). `Successed` naming (rule 2) applies to any handler added later (the `SafetyLayer` itself returns `SafeAiResult`, not `BaseResponse<T>`).
- `SafetyEvent.StudentId` is a plain `int` — no cross-module FK (module-isolation rule 1).
- **Runtime review gate coupling (R5):** the Safety Layer is the enforcement point that determines whether a newly-generated response is stored as `ReviewStatus = Approved` or `PendingReview` in `ai.AiResponseCache`. The `SafeAiResult` must carry the `Confidence` score from the model response so callers (P3-04/05/06 handlers) can apply the auto-approval threshold rule. Define `SafeAiResult.Confidence decimal?` as part of BE-1. The actual `UpsertAsync` into `AiResponseCache` is done by the feature handler (not by the Safety Layer itself) using the `Confidence` from `SafeAiResult`. This is architectural: the Safety Layer is the gatekeeper (pass/block/regenerate + confidence measurement); the cache handler is the writer. Ensure this coupling is documented in a code comment in `GenerateSafeAsync`.
