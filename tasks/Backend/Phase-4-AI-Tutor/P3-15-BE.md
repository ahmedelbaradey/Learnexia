## Status: PARTIALLY BUILT — gateway seam complete; offline jobs deferred to P3-15b.

**BE-1/2/3 BUILT (in `feat/P3-15-ai-batch-offline-pregeneration`):**
- `IAiBatchGateway` seam + result DTOs in `Shared.Contracts/Ai/`
- `ClaudeBatchProvider` registered with a named `claude-batch` HttpClient; dormant when key absent
- `DeterministicFakeBatchGateway` + 8 unit tests (all green, no live keys needed)

**BE-4/5 DEFERRED → P3-15b.** Reason: both offline jobs require
1. A `Shared.Contracts` cross-module seam into Learning to enumerate real `questionId`/`conceptId` values (module isolation — no cross-module FK), AND
2. Exact replication of the runtime cache key built by `ExplainConceptCommandHandler` / hint / why-wrong handlers (real `questionId ?? 0`, `difficulty:0`, grounding hash, model version, language). Without this, pre-warmed rows use fabricated conceptIds and wrong difficulty, producing keys that NEVER match runtime lookups (dead rows). A `GetHashCode()`-derived conceptId is also process-randomized in .NET, breaking idempotency across restarts.
Do NOT build the offline jobs until P3-15b establishes the Learning question/concept-enumeration seam.
