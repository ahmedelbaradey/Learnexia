## Lead decisions (resolved — recorded for traceability)

| # | Question | Decision |
|---|---|---|
| OQ-1 | Embedding model + dimension N (baked into schema) | **CLOSED — self-hosted BGE-M3, `vector(1024)`.** Cohere `embed-multilingual-v3` (also 1024-d) is a future column-compatible alternative via a new per-model table; not used at MVP. |
| OQ-2 | Distance metric: cosine vs L2? | **Cosine** (`vector_cosine_ops`, `<=>`) — standard for normalized BGE-M3 embeddings. |
| OQ-3 | How is query text embedded at runtime? | **CLOSED — `IEmbeddingProvider` → `BgeM3EmbeddingProvider` → synchronous self-hosted BGE-M3 TEI HTTP endpoint (Hetzner).** NOT the P3-01 AI Gateway, NOT the async `PipelineJobs` poller (that seam is for offline ingestion only). |
| OQ-4 | Vector index type: HNSW vs IVFFlat? | **HNSW** for the seeded corpus (on `chunk_embeddings_bge_m3.Vector`); flag for tuning at BL-05 scale. |
| OQ-5 | Internal service seam vs HTTP endpoint? | Internal service (`RagContextProvider`); optional dev-only HTTP endpoint for api-tester. |
| OQ-6 | New `Curriculum` module vs fold into `Learning`? | **CLOSED — new `Curriculum` module APPROVED** (SRS/architecture explicit; lead-approved per CLAUDE.md ask-before-new-modules). |
| OQ-7 | Similarity floor/threshold for "no relevant context"? | Empirically calibrated against the seeded corpus; must be non-zero so the empty-retrieval signal is real. |
| OQ-8 | Seed corpus source | Thin representative slice per subject/grade from `info/`; confirm scope. |

## Acceptance-criteria coverage

- AC-1 (schema + extension): `CurriculumChunk` (no inline vector) + `CurriculumVersion` + **separate `chunk_embeddings_bge_m3` table with `Vector: vector(1024)`**; migration enables `CREATE EXTENSION IF NOT EXISTS vector`, applies against pgvector/pg17 → **BE-3, BE-4, BE-5**
- AC-2 (corpus seeded): pre-chunked corpus for 4 subjects/grades under an `Active` `CurriculumVersion`, BGE-M3 embeddings populated in `chunk_embeddings_bge_m3`, no OCR dependency → **BE-9**
- AC-3 (top-k filtered retrieval): JOIN query filtered by Active version + grade + subject + optional skill, ordered by vector distance → **BE-7**
- AC-4 (empty handling): similarity floor enforced; empty list returned when nothing clears the floor (`Successed = true`); callers can branch deterministically → **BE-7**
- AC-5 (latency): HNSW index on `chunk_embeddings_bge_m3.Vector` prevents full-scan; self-hosted BGE-M3 TEI keeps query embedding within NFR-1 (< 4 s) → **BE-4, BE-5, BE-6**
- AC-6 (conventions): `BaseResponse<T>`, no UoW, `ILoggerManager`, no cross-module FK, schema `curriculum` → **BE-7, BE-10**
- **`RagContextProvider` seam:** implements `ILearningContextProvider`; non-empty for seeded skills; empty `Chunks` (not exception) for out-of-corpus queries; config-key registration enables swap from `SeededCorpusContextProvider` → **BE-11**
