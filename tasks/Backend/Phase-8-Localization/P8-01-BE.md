## Acceptance-criteria coverage
- `LearningLanguage` attribute, separate from `PreferredLanguage` → **BE-1, BE-2**
- Parent sets it at onboarding, required → **BE-3**
- Immutable by student (no student-facing mutation added) → **BE-3** (only parent/onboarding writes it; change path is P8-04)
- JWT claim `learning_language` re-issued on refresh → **BE-4**
- `/Me` returns it; UI language defaults to match → **BE-5**

## Notes
- **Identity-module-scoped**; no cross-module FK. New modules use deferred commit + `UnitOfWorkBehavior` (ADR 0001); `BaseResponse<T>` + `Successed`.
- Do **not** add a student-facing endpoint to change `LearningLanguage` — that is parent-only in **P8-04**.
- Security-sensitive (child data + auth claim) → `security-auditor` before the gate.
