## Acceptance-criteria coverage
- Single resolver (ARABIC/ENGLISH pinned; MATH/SCIENCE follow learner) → **BE-2**
- All curriculum reads return the resolved tree → **BE-3, BE-4, BE-5**
- Edge-case matrix verified → **BE-7**
- Fallback + log → **BE-6**
- Language from JWT claim, not query param → **BE-1**

## Notes
- **Learning-module-scoped**; reads learning language from the JWT claim (no cross-module call). Queries are not auto-validated (validate inputs in-handler).
- `BaseResponse<T>` + `Successed`; `ProjectTo` + paginate where lists are returned.
- Coordinate with P8-02 (the `Subject.Language` column the filters depend on).
