> - **Embedding model:** BGE-M3 (multilingual, 1024-dim). Vectors stored in the `vector(1024)` column from BL-04. Cohere `embed-multilingual-v3` is the paid alternative (also 1024-dim). Verify BGE-M3 license before adopting.
> - **Chunking strategy:** Arabic sentence/paragraph boundary chunking (NOT naive token-count splitting — Arabic morphology requires linguistic boundaries). Our custom Claude prompting + post-processing owns that mapping.
> - **Human review before publish — ON by default:** Arabic OCR + LLM structuring error rates are higher than English. Low-confidence items MUST be flagged for review and withheld from students; this is the top quality lever. Auto-publish of ingested Arabic content to students is NEVER done. The review queue (Q4) is the enforcement mechanism. This is not optional.

## Notes

- **Lead-approved stack (do not re-litigate):** RAG-Anything orchestrates chunking/embedding; BGE-M3 (1024-dim, multilingual) is the embedding model (Cohere embed-multilingual-v3 is the paid alternative, also 1024-dim); chunking uses Arabic sentence/paragraph boundaries with grade-scope enforcement; hierarchy mapping is a CUSTOM Claude-driven layer (offline lane); human review before publish is ON by default — no auto-publish of Arabic ingested content to students ever.
- **Decision D — NO inline vector on `CurriculumChunk`:** The `EmbeddingVectorRef` column does NOT exist on `CurriculumChunk`. Embeddings are written to the `chunk_embeddings_bge_m3` physical table (C# entity `ChunkEmbeddingBgeM3`, BL-04-BE-7) by BL-05-PY-4b (if in scope) or P3-07. The table's `vector(1024)` column is fixed — a different-dimension future model requires a new physical table (e.g. `chunk_embeddings_openai_3072`). Any implementation that sets an embedding field on `CurriculumChunk` is incorrect and blocks the reviewer gate.
- **Decision B — ProvenanceRef + ProvenanceMapping:** each `CurriculumChunk` row must have a `ProvenanceRef` (string reference to the source page/block) and a corresponding `ProvenanceMapping` record. BE-5 sets `ProvenanceRef`; BE-11 creates `ProvenanceMapping`. The `ContentSource`/`Chapter` tree was created by BL-02-BE-6 — it must exist before BE-11 runs.
- **Decision C — Version association:** all new chunks and hierarchy nodes are Draft-version-associated (BE-12). No content is Active without P7-05's publish action. RAG retrieval (P3-07) must filter `Status = 'Active'` on `CurriculumVersion` — document this requirement in P3-07's task file as a forward note.
- **Cross-module write risk (if option A):** BL-05-BE-5 writing to `learning`'s hierarchy from a `curriculum` module requires `Shared.Contracts` events. This is non-trivial — the strongest technical argument for BL-04 option B. Lead must decide before BE-5 is implemented.
- **P2-10 natural-key upsert pattern** (from `LearningSeeder.EnsureSkillAsync`) is the reference for idempotent hierarchy writes. Mirror it exactly; do NOT duplicate subject/unit/lesson names on re-ingest.
- **Idempotency keys:** `(SubjectName, GradeId)` for Subject; `(UnitName, SubjectId)` for Unit; `(LessonName, UnitId)` for Lesson; `(ConceptName, LessonId)` for Concept; `(SkillName, ConceptId)` for Skill. Must not clobber P2-10's hand-seeded demo data — confirm with lead (Q3).
- **Embedding model lock (Decision D):** BGE-M3 / Cohere embed-multilingual-v3 both output 1024-dim (compatible with `chunk_embeddings_bge_m3.Vector vector(1024)`). A different-dimension model requires a new physical table (e.g. `chunk_embeddings_openai_3072` with `vector(3072)`). All embedding calls must pass diacritized Arabic text — do not normalize/strip tashkeel before embedding.
- **Embedding generation (Decision D):** BL-05-PY-4b generates embeddings (in `ResultJson`) and the .NET poller (BE-13 → BE-5) writes them to `chunk_embeddings_bge_m3` (not to `CurriculumChunk`). If Q6 resolves as "P3-07 generates," skip PY-4b; P3-07 writes to `chunk_embeddings_bge_m3`. Confirm with lead.
- **Cross-process transport — DB-outbox + Python poller (DECIDED):** BE-13 (.NET `BackgroundService`) polls `PipelineJobs WHERE JobType='ingest'`; PY-6 (Python) polls + claims + writes results. MediatR events are NOT the transport. No external broker. See `curriculum-system-of-record.md` §4b.
- **Confidence threshold** is config-driven (default 0.7); do NOT hardcode.
- **Security-auditor gate REQUIRED** (LLM/AI surface, admin data writes, prompt-injection risk, must not corrupt P2-10 demo data, Claude API key in secrets).
- No designer stage; no student-facing UI for this story (admin review UI is likely deferred FE).
- All BGE-M3 / RAG-Anything specifics are "recommended-and-benchmark-to-confirm," not absolute guarantees. Verify licenses before adopting.
