## Contract from Backend (P7-06-BE)
- `GET /api/Admin/Users?role=&status=&q=&page=&pageSize=` → `BaseResponse<PagedResult<AdminUserListItemDto>>`.
- `GET /api/Admin/Users/{id}` → `BaseResponse<AdminUserProfileDto>`; `/{id}/family` → `FamilyDto`; `/{id}/activity` → `ActivitySummaryDto`.

## Notes
- Pure read surface — no mutations. Reuses shared packages so contracts stay consistent with the student app. Activity numbers come pre-aggregated from the backend (cross-module via contracts); the FE does not call other modules directly. RTL/Arabic + English per project i18n.
