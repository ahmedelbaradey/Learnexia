- `POST/PUT/DELETE` Quizzes & Questions → `BaseResponse<Guid>`/`<bool>`; invalid type shape → `Successed=false` + message.
- `POST .../Quizzes/{id}/Attach` (lessonId|skillId) + `PUT .../Questions/Reorder` → `BaseResponse<bool>`.
