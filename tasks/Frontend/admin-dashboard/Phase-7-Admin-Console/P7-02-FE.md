## Contract from Backend (P7-02-BE)
- `GET /api/Learning/Units/{unitId}/Lessons` and `.../Lessons/{id}/ContentBlocks` → `BaseResponse<List<...>>`.
- `POST/PUT/DELETE` Lessons & ContentBlocks → `BaseResponse<Guid>`/`<bool>`; `PUT .../Reorder` → `BaseResponse<bool>`.

## Notes
- A lesson's language is **inherited** from its owning Subject's `(subjectCode, language)` tree — there is no per-lesson language picker; the editor only displays it (read-only) so authors write content in the correct medium. TanStack Query v5 + Zustand v5; RTL/Arabic + English.
- Content-block `payload` is type-shaped JSON; renderers live in `packages/ui` where reusable by the student app later.
