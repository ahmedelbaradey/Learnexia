## Acceptance-criteria coverage
- Entries show actor/action/target/time/before-after → **FE-2, FE-3**
- Append-only/immutable: no edit/delete controls in UI → **FE-3, FE-5**
- Paginated, searchable/filterable by actor/action/target/date → **FE-2**
- Export filtered log (CSV/JSON) → **FE-4**
- Admin-only read; non-admin → 403/redirect; view-only → **FE-5**
- RTL/EN → **FE-6**

## Contract from Backend (P7-12-BE)
- `GET /api/Audit/Log?actor=&actionType=&target=&dateFrom=&dateTo=&page=&pageSize=` → `BaseResponse<PagedResult<AuditLogDto>>` (`{ id, actor, actionType, target, occurredAt, before, after }`).
- `GET /api/Audit/Log/Export?<same filters>&format=csv|json` → file stream.
- No mutation endpoints — log is read-only.

## Notes
- This screen is strictly read-only; never render edit/delete affordances. Mirror existing admin table screens; do not invent new abstractions. Before/after snapshots may contain sensitive references — display only, never editable.
