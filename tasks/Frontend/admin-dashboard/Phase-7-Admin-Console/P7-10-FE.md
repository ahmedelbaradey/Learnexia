## Acceptance-criteria coverage
- KPI cards over a selectable range → **FE-3** (+ FE-5)
- Charts/trends with subject/grade breakdown → **FE-4**
- Aggregates only, no child PII → consumes aggregate endpoints (**FE-2**, + P7-10-BE)
- Fast/cached, no latency hit → backend (P7-10-BE-4); FE caches via TanStack Query (**FE-2**)
- Admin-only access (non-admin redirect) → **FE-1**
- Date-range filtering → **FE-5**

## Contract from Backend (P7-10-BE)
- `GET /api/Admin/Analytics/kpis?from=&to=&subject=&grade=` → `BaseResponse<PlatformKpiSummaryDto>`.
- `GET /api/Admin/Analytics/trend?metric=&from=&to=&groupBy=` → `BaseResponse<KpiTrendDto>` (`{ bucket, value }` series). Both admin-gated; read `Successed` from the envelope.

## Notes
- Built on the P1-10 admin shell; reuses shared packages so admin stays contract-consistent with the student app. Read-only dashboard — no mutations. Charts are admin-facing (web). RTL/Arabic + English. Show aggregates only — never per-child PII on this dashboard.
