## Acceptance-criteria coverage
- Skill CRUD with threshold/time/owner → **FE-1**
- Add prerequisite edge → **FE-3**
- Cycle rejected with clear error, no persist → **FE-4**
- List prerequisites-of / unlocked-by → **FE-5**
- Remove edge, graph re-renders → **FE-3**
- Admin-only access → guard + middleware (across pages)

## Contract from Backend (P7-03-BE)
- `GET /api/Learning/Skills/Graph?subjectId=` → `BaseResponse<SkillGraphDto>` (nodes[], edges[]).
- `GET .../Skills/{id}/Prerequisites` + `.../UnlockedBy` → `BaseResponse<List<SkillDto>>`.
- `POST/PUT/DELETE` Skills + `POST/DELETE .../Skills/Edges` → `BaseResponse<Guid>`/`<bool>`; cycle → `Successed=false` + message.
