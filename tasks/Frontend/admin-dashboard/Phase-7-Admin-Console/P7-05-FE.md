## Acceptance-criteria coverage
- Edits as draft, not served to students → **FE-1, FE-5**
- Publish records versioned snapshot, per `(subjectCode, language)` tree → **FE-2**
- Live vs pending-draft distinguishable, per language tree → **FE-1, FE-5**
- Preview draft as student without publishing, in the tree's language → **FE-3**
- Revert/rollback restores previous version → **FE-4**
- Per-language publication coverage visible → **FE-6**
- Admin-only access → guard + middleware

## Contract from Backend (P7-05-BE)
- `GET .../{type}/{id}?view=admin` (live + draft) / `?view=student` (latest published) → `BaseResponse<...>`.
- `POST .../{type}/{id}/Publish` + `.../Rollback` → `BaseResponse<int>` (version no.).
- `GET .../{type}/{id}/Preview` → `BaseResponse<...>` (student-rendered draft).

## Notes
- Publish/version/preview are **per `(SubjectCode, Language)` tree** — the parallel ar/en trees publish and version independently, so one language can be live while the other is still draft. Preview renders in that tree's language (direction + locale). Coverage shows ar/en publication state side by side.
- Preview reuses the P7-02 content-block renderers and P7-04 question renderers so admins see true student rendering. TanStack Query v5 + Zustand v5; RTL/Arabic + English.
