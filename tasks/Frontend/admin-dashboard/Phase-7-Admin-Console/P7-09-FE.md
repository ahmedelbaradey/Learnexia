## Acceptance-criteria coverage
- Paginated queue with source/submitter/ref/status → **FE-2** (+ P7-09-BE-4)

- Reject reason required; action reflects new status → **FE-4**

- Admin-only; non-admin → 403/redirect → **FE-5** (+ P7-09-BE-8)
- RTL/EN → **FE-6**

## Contract from Backend (P7-09-BE)
- `GET /api/Moderation/Queue?status=&source=&subject=&grade=&dateFrom=&dateTo=&search=&page=&pageSize=` → `BaseResponse<PagedResult<ModerationItemDto>>`.
- `GET /api/Moderation/{id}` → `BaseResponse<ModerationItemDetailDto>`.
- `POST /api/Moderation/{id}/Review` `{ decision: 'Approve'|'Reject'|'Flag', reason? }` → `BaseResponse<ModerationItemDto>`; reason required for Reject.
