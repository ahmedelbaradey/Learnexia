## Contract from Backend (P7-01-BE)
- `GET /api/Learning/Subjects` → `BaseResponse<List<SubjectDto>>`; `.../Subjects/{id}/Units` → list.
- `POST/PUT/DELETE` Subjects & Units → `BaseResponse<Guid>`/`<bool>`; `PUT .../Reorder` + `.../Active` → `BaseResponse<bool>`.

## Notes
- Curriculum is **bilingual parallel trees**: each subject exists as `(SubjectCode, Language)` — MATH/SCIENCE/ARABIC/ENGLISH × ar/en, 6 per grade; the Arabic subject is pinned `ar` and the English subject is pinned `en`. Screens must be **language-tree aware**: use `subjectCode` (not display name) for identity/icons, and never mix languages in a single reorder/coverage view. `LearningLanguage` (the learning medium, surfaced here) is separate from `PreferredLanguage` (admin/student UI language).
- Builds on the P1-10 admin shell; add a Curriculum nav section. TanStack Query v5 + Zustand v5; RTL/Arabic + English. Reuse Tamagui `packages/ui` components.
