> Phase 4 — AI Tutor · SP: 5 · FR-AI-1, FR-AI-2 · Est. hours · App: **apps/student-app** (Expo universal)
>
> **AI Helper MVP — read first:** See `docs/briefs/ai-helper-mvp.md`. P3-12 surfaces exactly the **four allowed helper intents** as distinct labeled affordances — **no free-text chatbot input**. The four UI actions are: "اشرح السؤال" (Explain), "اديني تلميح" (Hint), "ليه إجابتي غلط" (WhyWrong — chip appears after wrong answer, sources the student's submitted answer from quiz state, no text field), "اديني مثال مشابه" (SimilarExample). Plus the **redirect state** (friendly bubble copy when no context is available). Build order is NOT gated on P3-07/BL-*.

> **Status: 🔲 Not started** — hard-blocked by P3-04 (explain endpoint + wire format including redirect event published) + P3-05 (hint/WhyWrong/simplify endpoints) + P3-06 (SimilarExample endpoint). Also requires the designer Design Spec (`design-system/ui_kits/student-mobile/P3-12-ai-tutor.md`) to complete before the frontend batch. P3-07 is NOT required.

> **Note on thin P3-04/P3-05/P3-06 FE surface:** P3-04, P3-05, P3-06 (SimilarExample) are backend-only stories. Any frontend integration points they introduce (wiring the live streams, enabling action affordances) are folded into this file rather than separate FE task files for those stories.

## Contract from Backend (P3-04 / P3-05 / P3-06)

- Explain: `POST /api/AiTutor/Explain` — SSE response; `data:` text lines, `data: [DONE]` sentinel, `event: error` with typed payload, **`event: redirect` with `{ copy: string, skillName: string }` payload** (new). Body: `{ lessonId?, conceptId?, skillId? }`. **No `question` free-text body field** (scope constraint).
- Hint: `POST /api/AiTutor/Hint` — SSE response; same format + metadata preamble event with `{ hintLevel, nextHintLevel }` (Hint intent only). Body: `{ questionId, attemptId, intent: "Hint"|"WhyWrong", hintLevel?, wrongAnswer? }`. `wrongAnswer` required for `WhyWrong` intent.
- Simplify: `POST /api/AiTutor/Simplify` — SSE response; same format as Explain. Body: `{ lessonId?, conceptId? }`.
- SimilarExample: `POST /api/AiTutor/SimilarExample` — SSE response; same format as Explain (includes `event: redirect`). Body: `{ skillId, questionId? }`.
- All endpoints: `[Authorize(Roles="Student")]` — child JWT required.
- **Wire format (including `event: redirect` shape) must be pinned and published in HANDOFF.md before the frontend batch is dispatched (OQ-2 gate).**
