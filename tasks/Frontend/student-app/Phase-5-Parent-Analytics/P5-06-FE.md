## API contract (backend BUILT 2026-06-22 — implement FE against this)
- **Endpoint:** `PUT api/Parent/Children/{childId}/Grade` · auth: parent JWT (roles `Parent`/`Admin`/`SuperAdmin`).
- **Request body:** `{ "targetGrade": <int 1–6> }` (`childId` is the route param; do NOT send it in the body).
- **200 success / no-op:** `{ "successed": true, "message": "<localized>", "data": { "childId", "oldGrade", "newGrade", "isNoOp" } }` — `isNoOp:true` when `targetGrade` equals the current grade (treat as success, refetch is a no-op). All responses use the `BaseResponse<T>` envelope (success flag spelled **`successed`**).
- **Errors:** `401` no JWT · `403` not-your-child **or** unknown child (identical generic message — anti-enumeration; never reveal which) · `422` grade outside 1–6 (`errors[].propertyName == "TargetGrade"`).
- After a non-no-op 200, refetch the child's dashboard/skill-tree (server re-scopes lazily at read time; XP/badges/streaks/mastery carry over unchanged).

## Notes
- The destructive-sounding action is reversible (parent can transition again) but a **confirmation step is required** (clear "history preserved" copy) so it isn't triggered accidentally.
- Mirrors existing parent-dashboard component + api-client shapes (rule #8 — ask before new patterns). Backend (`P5-06-BE`) ships the endpoint + re-scope.
