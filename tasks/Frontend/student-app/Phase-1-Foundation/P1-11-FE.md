## Pixel-perfect rule (applies to every task)
Build to the named `design-system/screenshots/web/<page>.png` exactly — layout, spacing, color tokens (`--lx-*`), radii, typography (Poppins/Tajawal/Cairo per the `--lx-font-*` roles), and component states. Any deviation must be a documented design note. Verify against the capture before marking done.

## What already exists (drives the reslice — reuse, don't rebuild)
- **Fonts** Poppins/Tajawal/Cairo are **already wired** in `packages/design-system/src/tamagui.config.ts` → no font task.
- **Themes** `darkTheme` + `lightTheme` **already exist**; `LearnexiaProvider` takes a `theme` prop → only a runtime **toggle + persistence** is new.
- **i18n / RTL** already works (`changeLocale`, `localeStore`) → only the **switch affordances** are new.
- **Add-child / link-child / children** routes **already exist** (`(onboarding)/add-child.tsx`, `(parent)/children.tsx`, `link-child.tsx`, `ChildCard`) → reskin to pixel-perfect, not build.
- **No chart component** exists (only `XPBar`) → the daily-activity / 20-day / time-of-day charts are the real cost + risk → extracted as a shared enabler (FE-2).
