## Acceptance-criteria coverage
- Parent-only, family-scoped change; student cannot → **FE-2, FE-6** (+ BE enforces 403)
- Explicit confirm flag or no change → **FE-3** (sends `confirmFreshStart`; BE returns 424 without it)
- Update + reset Math/Science only; Arabic/English + gamification retained → **FE-3 copy** (+ BE-5/BE-6 do the reset)
- New `learning_language` on next sign-in → handled by BE token re-issue (no FE work)
