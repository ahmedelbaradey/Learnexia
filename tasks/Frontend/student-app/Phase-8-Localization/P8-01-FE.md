## Acceptance-criteria coverage
- Child carries a `LearningLanguage` separate from UI language; required at add-child → **FE-1, FE-2** (+ BE)
- Required, parent-set → **FE-1, FE-2**
- Immutable by student (no student-facing add/change path) → covered by absence (parent-only form)
- UI `PreferredLanguage` defaults to match the learning language, still editable → **FE-3**
- Value sent + surfaced (`/Me` returns `learningLanguage`) → **FE-4** (+ BE, JWT claim is BE)

## Contract from Backend (P8-01-BE, merged)
- `AddChildCommand` gains `learningLanguage` (required); `/Me` / child projection returns `learningLanguage`; `learning_language` JWT claim is issued/refreshed. **All exposed only after the api-client regen** (P8-99-FE-0).
