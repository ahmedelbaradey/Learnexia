## Schema gap analysis

**Result: MIGRATION REQUIRED.**

The current `Lesson.cs` entity (confirmed by reading the file) has ONLY: `Name`, `Difficulty`, `SequenceOrder`, `IsLocked`, `UnitId/Unit`, `SkillId?/Skill`. It has NO `Explanation` column and NO `Visual` column.

Q1 (Option A, approved) requires two new nullable columns on `learning.Lessons`:

| Column | EF type | DB type | Nullable | Max length |
|---|---|---|---|---|
| `Explanation` | `string?` | `text` | YES (NULL) | none — use `.HasColumnType("text")` |
| `Visual` | `string?` | `varchar(1024)` | YES (NULL) | 1024 — use `.HasMaxLength(1024)` |

**Migration name:** `AddLessonContent` (matches PascalCase convention of `AddQuizTables`, `AddAttemptQueryIndexes`, `AddSkillGraphTables` in the existing migration folder).

**Schema:** `learning` (all Learning module tables are in this schema per `LearningSchema.Name`).

**No new index needed** — neither column is a filter target.

**No foreign keys added.** Purely additive — two nullable columns; no impact on existing rows (both default to NULL).

**`LessonConfig.cs` must be updated** to declare both new properties (optional HasMaxLength for `Visual`; no annotation needed for `Explanation` since text is the PostgreSQL default for `string` without max length, but being explicit avoids EF choosing `varchar(max)`).

#### Step B — Rewrite `GetLessonQueryHandler`

**File:** `backend/src/Modules/Learning/Learnexia.Modules.Learning.Application/Features/Lessons/Queries/Get/GetLessonQueryHandler.cs`

Replace the entire current handler. The current handler delegates to `_service.LessonService.GetByIdAsync<SingleLessonResponse>(...)` and leaks `ex.Message` in the catch block (line 29). The new handler hand-rolls the load, fixes the leak, returns `NotFound` on a missing lesson, and fills `QuickCheck` manually.

New handler specification:

1. Inject `ILearningRepositoryManager _repository`, `IMapper _mapper`, `ILoggerManager _logger`, `IStringLocalizer<SharedResources> _localizer`. Remove `ILearningServiceManager` (no longer needed in this handler).
2. Load `Lesson` by id: `_repository.Learning.GetByCondition<Lesson>(l => l.Id == request.Id, false).FirstOrDefault()`. If null → `NotFound<SingleLessonResponse>(_localizer[SharedResourcesKey.LessonNotFound])`. (`LessonNotFound` key already exists — confirmed present from P2-06's `StartAttemptCommandHandler`; do NOT add a duplicate key.)
3. Load first `QuizQuestion` for the lesson: `_repository.Learning.GetByCondition<QuizQuestion>(q => q.LessonId == request.Id, false).OrderBy(q => q.Id).FirstOrDefault()`. Result may be null (lessons without questions → `QuickCheck = null`).
4. Map `Lesson → SingleLessonResponse` via AutoMapper: `var dto = _mapper.Map<SingleLessonResponse>(lesson)`.
5. If `firstQuestion != null`: `dto.QuickCheck = _mapper.Map<QuizQuestionDto>(firstQuestion)` (reuses `QuizProfile`'s `QuizQuestion → QuizQuestionDto` map which already excludes `CorrectAnswer`).
6. Return `Success(dto)`.
7. **Catch block:** `return ServerError<SingleLessonResponse>();` — NO `ex.Message` argument. The fix for Q12 is exactly this replacement (the current offending line is `return ServerError<SingleLessonResponse>(ex.Message);`).

**UoW note:** no `SaveChangesAsync`. Query handler; no writes.

**Demo lesson lookup:** the 4 target lessons are the first lesson of the first unit of Grade-1 for each subject — matching names confirmed in the brief:

- Science G1: `"What Are Living Things? (G1)"`
- Arabic G1: `"Arabic Alphabet Review (G1)"`

**Idempotency rule:** before updating a lesson's content or inserting a QuizQuestion, check:
- `lesson.Explanation != null` → skip (already seeded; don't overwrite).
- `db.QuizQuestions.Any(q => q.LessonId == lesson.Id)` → skip QuizQuestion insert (already seeded).

This ensures re-running the seeder on an already-seeded DB adds zero rows and changes no existing data.

**`CorrectAnswer` encoding (critical):** `QuizQuestion.CorrectAnswer` is `jsonb` in PostgreSQL (confirmed in HANDOFF — P2-07 found this). A bare string like `option_b` is invalid JSON. The stored value must be a JSON-encoded string, e.g. `"\"6\""` in C# (which serializes to the JSON value `"6"`, a quoted string). Mirror exactly how `P2-07` integration tests seed correct answers.

```csharp
private static async Task SeedDemoLessonContentAsync(LearningDbContext db, ILoggerManager? logger)
{

    // Name-based lookup is safe: P2-10 names are stable lookup keys (HANDOFF contract).
    var demoLessonNames = new[]
    {
        "Introduction to Counting (G1)",
        "What Are Living Things? (G1)",
        "Arabic Alphabet Review (G1)",
        "Sight Words and Fluency (G1)"
    };

    foreach (var lessonName in demoLessonNames)
    {
        var lesson = await db.Lessons.FirstOrDefaultAsync(l => l.Name == lessonName);
        if (lesson is null)
        {
            logger?.LogWarning($"SeedDemoLessonContent: lesson '{lessonName}' not found; skipping.");
            continue;
        }

        // Idempotency: only seed if not already seeded.
        if (lesson.Explanation is null)
        {
            lesson.Explanation = /* per-lesson content */;
            lesson.Visual = /* per-lesson URL */;
            db.Lessons.Update(lesson);
        }

        var hasQuestion = await db.QuizQuestions.AnyAsync(q => q.LessonId == lesson.Id);
        if (!hasQuestion)
        {
            var question = new QuizQuestion
            {
                LessonId = lesson.Id,
                QuestionType = QuestionType.MCQ,
                QuestionText = /* per-lesson question */,
                Options = /* JSON array of 4 quoted-string options */,
                CorrectAnswer = /* JSON-encoded correct option string */,
                Difficulty = DifficultyLevel.Easy,
                GeneratedBy = GeneratedByType.Human,
                CreatedBy = SystemUserId
            };
            await db.QuizQuestions.AddAsync(question);
        }
    }

    await db.SaveChangesAsync();   // Seeder is allowed to call SaveChangesAsync directly

}
```
