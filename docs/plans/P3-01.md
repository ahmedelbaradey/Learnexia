## Execution batches

### Batch 1 — SEQUENTIAL — `backend-feature` — BE-1 then BE-2

**Mode:** Sequential (module scaffold depends on the contracts existing first).

**BE-1:** Create `Shared.Contracts/Ai/` and all contract files (`IAiGateway`, `AiRequest`, `AiResult`, `AiError`, `AiUsage`, `AiChunk`, `AiTaskKind`, `AiModelTier`). Keep provider-neutral — no provider SDK types in the contract. Include the `StreamAsync(AiRequest, CT) : IAsyncEnumerable<AiChunk>` signature even though the SSE endpoint is deferred to P3-04.

**BE-2:** Scaffold the `Ai` module four layers:
- `Learnexia.Modules.Ai.Domain` (no deps)
- `Learnexia.Modules.Ai.Application` (ref Domain + Shared.Contracts)
- `Learnexia.Modules.Ai.Infrastructure` (ref Application + Shared.Contracts — **only project referencing provider SDK**)
- `Learnexia.Modules.Ai.Api` (ref Application + Shared)

Add all four `.csproj` files to `Learnexia.Modular.sln` (serialized shared-file edit — coordinate with any in-flight story that edits the `.sln`). Create `AiModule.cs` extension class in `Ai.Infrastructure` as the DI entry point.

**Gate after Batch 1:** `dotnet build backend/Learnexia.Modular.sln` green. Module structure exists. `Shared.Contracts/Ai/` types compile.

### Batch 2 — SEQUENTIAL — `backend-feature` — BE-3

**BE-3:** Add `AiGatewayOptions`:
```
DefaultProvider (string)
Models (Dictionary<string, ModelConfig>  — keyed by "taskKind:tier")
TimeoutSeconds (int, default 30)
RetryCount (int, default 3)
RetryBackoffSeconds (double, default 1.0)
```
Bind from `Ai:Gateway` section via `IOptions<AiGatewayOptions>`. API keys are **not** in this options object — they are sourced from `IConfiguration` secret sections / env vars (e.g. `Ai__Providers__Claude__ApiKey`) at `HttpClient` construction time. Never log the key; never commit it.

**Gate after Batch 2:** Options class compiles; build green.

---

### Batch 3 — PARALLEL — `backend-feature` (three independent threads) — BE-4, BE-5, BE-6

All three are independent after BE-3. File isolation is clean.

**BE-4 (AiModelRouter):**
- Pure mapping: `(AiTaskKind, AiModelTier?) + AiGatewayOptions.Models → (providerName, modelId)`.
- No I/O. Fully unit-testable.
- Default routing table: `Hint → (Claude, claude-haiku-4-5)`, `SimpleExplanation → (Claude, claude-haiku-4-5)`, `HardReasoning → (Claude, claude-opus-4-8)`, `QuestionGeneration → (Claude, claude-opus-4-8)`. All overridable from config.
- Unit tests: every `AiTaskKind` value routes to the expected tier/model; a config-level override changes the route without recompile.

**BE-5 (ClaudeProvider):**
- Implements `IAiProvider`.
- Uses a named `HttpClient` (registered in BE-8 via `IHttpClientFactory` — the provider receives `IHttpClientFactory` and resolves the named client).
- Reads API key from `IConfiguration["Ai:Providers:Claude:ApiKey"]` (secret store / env).
- Maps Anthropic API response to `AiResult`; maps HTTP 4xx/5xx/timeout to typed `AiError`.
- `CancellationToken` threaded end-to-end.
- **No API key in logs, error messages, or `AiUsage` records.**

**BE-6 (Second provider adapter):**
- `OpenAiProvider : IAiProvider` (or `GeminiProvider`) — at minimum a real HTTP call, not a stub. Enough to prove the `IAiProvider` contract is complete and the router can swap to it.
- Same key-handling pattern as BE-5.

**Gate after Batch 3:** All three compile and their unit tests (`AiModelRouterTests`) pass. Build green.

### Batch 4 — SEQUENTIAL — `backend-feature` — BE-7 then BE-8 then BE-9

**BE-7 (AiGateway facade):**
- Resolves `IAiProvider` via `AiModelRouter` (and a provider registry keyed by `providerName`).
- Retry policy: exponential backoff on transient (429, 5xx, timeout); bounded by `AiGatewayOptions.RetryCount`. Polly or a manual retry loop — no unbounded loop.
- Hard timeout: `CancellationTokenSource.CreateLinkedTokenSource(ct, TimeoutCts)` where `TimeoutCts` is seeded from `AiGatewayOptions.TimeoutSeconds`. Honors NFR-1 (< 4 s budget).
- Exception translation: provider exception → `AiError(AiErrorKind.Unavailable, "AI service temporarily unavailable")` or `AiError(AiErrorKind.Timeout, "AI request timed out")`. **Never** echoes provider error body, stack trace, or internal message.
- `AiUsage` capture: `PromptTokens`, `CompletionTokens`, `LatencyMs`, `EstimatedCostUsd` (approximated from model rates in config), `ModelId`, `Provider`. Logged via `ILoggerManager` at Debug. Not persisted (log-only, Q5).
- Returns `AiResult` with `Successed = false` on any failure — never throws to the caller.

**BE-8 (DI wiring):**
- Register named `HttpClient` instances for each provider via `services.AddHttpClient("claude", c => { c.BaseAddress = …; })`.
- Register `IAiGateway → AiGateway`, provider registry, `IAiModelRouter → AiModelRouter`.
- Bind `AiGatewayOptions` to `Ai:Gateway` section.
- Add `Directory.Packages.props` entry for any NuGet packages needed (e.g. Polly if used — **serialized edit, coordinate**).

**BE-9 (Program.cs + architecture test):**
- Add `builder.Services.AddAiModule(builder.Configuration)` to `Program.cs` (**serialized edit, coordinate**).
- Architecture test (`ArchTests` project, using `NetArchTest` or `ArchUnitNET`):
  - Assert: no type in any assembly **other than** `Learnexia.Modules.Ai.Infrastructure` references any provider SDK namespace (e.g. namespaces starting with `Anthropic.`, `OpenAI.`, `Google.Apis.`).
  - This enforces AC1 by construction.

**Gate after Batch 4:** `dotnet build` green. `dotnet test` passes (router unit tests + architecture test). DI resolves — verify by running the host and checking startup logs (no DI exception).

### Batch 5 — SEQUENTIAL — `security-auditor` (MANDATORY gate)

**Focus areas (per brief handoff):**
1. **Provider API keys:** never committed, never in appsettings checked into git, never in logs, never in `AiUsage` records. Secret-store / env sourcing verified.
2. **Outbound trust boundary:** prompts sent to LLMs must not carry unscrubbed child PII (P3-03 owns scrubbing; P3-01 must not log prompt bodies that may carry PII).
3. **Error leakage:** provider stack traces / internal error bodies must not reach client or logs in raw form. Verify `AiGateway` translates exceptions correctly.
4. **DoS / cost-exhaustion:** retry policy is bounded (count + backoff), hard timeout caps the call. Verify `RetryCount` and `TimeoutSeconds` are finite and have sane defaults.
5. **Usage log:** confirm no prompt/response text or student PII is in the log entries.

**Critical/High findings block the reviewer gate.**

### Overall story DoD (tied to acceptance criteria)

- **AC1:** `IAiGateway` is the single public entry point. No feature handler references a provider SDK type. Architecture test asserts and passes in CI.
- **AC2:** `AiModelRouter` routes each `AiTaskKind` to the correct tier/model from config. Two provider adapters exist and are swappable behind `IAiProvider`. Unit-tested.
- **AC3:** Provider outage (5xx) → typed `AiError(Unavailable)`; timeout → `AiError(Timeout)`; retry is bounded + backed off; no raw provider error body in response or logs.
- **AC4:** Changing `Ai:Gateway:DefaultProvider` or `Ai:Gateway:Models:*` in config changes behavior without recompile. Keys sourced from secret store, never literals.
- **Usage:** per-call tokens/latency/cost logged at Debug via `ILoggerManager`. No PII, no prompt/response body.
