### Batch 1 — Motion infra (SEQUENTIAL, gates all screen batches)

**Agent:** `frontend`
**Mode:** Sequential — must complete before FE-1..FE-6.
**Depends on:** Designer stage complete.

**Task: P4-08-FE-7**

Three deliverables in `packages/ui`:

**1 — `packages/ui/src/internal/ConfettiLayer.tsx` (replace stub with real Skia particle system)**

Replace the current ~18-line stub. Real implementation (~80–120 lines):
- Import via `tryLoadSkia()` (lazy, fail-soft — returns empty canvas when Skia unavailable).
- `Canvas` component from `@shopify/react-native-skia`.
- Particle pool: 40–60 `Circle` shapes. Each particle: `x`, `y`, `vx`, `vy`, `rotation`, `opacity`, `color` (from `CONFETTI_COLORS` palette already defined in the component header).
- `useFrameCallback` drives per-frame gravity update: `vy += 980 * dt`, `y += vy * dt`, `x += vx * dt`, `rotation += 3 * dt`.
- Lifetime: 2 s per particle. Particles fade out via opacity in the final 0.5 s of their lifetime.
- `active` boolean prop: when `false`, do not render (avoid background GPU draw).
- Reduce-motion: when `useReduceMotion()` returns `true`, render nothing (prop fallback, not animation skip).
- Web/native parity: Skia web mode (WASM) loads transparently; `tryLoadSkia()` returns null on failure → empty `View` fallback.

**2 — `packages/ui/src/hooks/useDashboardDiff.ts` (new)**

```typescript
// Hook shape:
export interface DashboardDiff {
  xpDelta: number;
  levelDelta: number;
  streakDelta: number;
  newBadges: string[];      // badge codes newly in recentBadges vs prior cache
  completedMissions: string[]; // mission codes whose status flipped to Completed
  tierChange: { from: string; to: string } | null;
}

export function useDashboardDiff(current: DashboardDto | undefined): DashboardDiff
```

Critical invariant: prior ref is `undefined` on cold start → first call returns zero-diff (no celebration fires on cold start). The ref is set AFTER the first successful response, not before.

Inputs compared: `xp`, `level`, `streakDays`, `recentBadges[].code` set diff, `dailyMissions[].status` + `weeklyMission?.status` flipped-to-Completed set, `leaguePreview.tierName` string diff.

**3 — `packages/ui/src/hooks/useReduceMotion.ts` (new)**

Thin cross-platform wrapper:
- On React Native: wraps Reanimated's exported `useReducedMotion()` (already available in `react-native-reanimated@^3.16.7`).
- On web (non-RN): reads `window.matchMedia('(prefers-reduced-motion: reduce)')`.
- Returns `boolean`. Export from `packages/ui/src/hooks/index.ts`.

**Completion gate:**
- `pnpm -F @learnexia/ui typecheck` — zero errors.
- `ConfettiLayer` renders 40+ particle circles on a Skia canvas and is gated by `active` prop.
- `useDashboardDiff(undefined)` returns all-zero diff (cold-start safety).
- `useDashboardDiff(A)` followed by `useDashboardDiff(B_with_new_xp)` returns `xpDelta > 0`.
- `useReduceMotion()` returns correct value in both environments.

#### Sub-batch 2a — FE-1: RewardOverlay + XP fill + lesson-complete wire

**New file: `packages/ui/src/components/RewardOverlay/index.tsx`**

Wrapper over the existing `RewardPopup` primitive (already in `@learnexia/ui`). Owns the combined-celebration card:
- Props: `rewards: { xp?: number; levelUp?: { from: number; to: number }; badges?: BadgeStateDto[]; missions?: MissionSummary[] } | null`, `onDismiss: () => void`.
- Renders modal-style overlay (Tamagui `Sheet` or `Dialog`). Single card listing all rewards. Dismiss button + auto-dismiss via `useEffect` with 5 s timeout.
- Fires `ConfettiLayer` when `levelUp` is present or any badge in `badges` is legendary/epic (`active={isLevelUp || hasBigBadge}`).
- `accessibilityRole="alert"`, `accessibilityLiveRegion="assertive"`.
- Reduce-motion: when `useReduceMotion()` → skip spring entrance, skip confetti; card still shows.

**Edit `apps/student-app/app/(child)/index.tsx`:**
- Import `useDashboardDiff` + `RewardOverlay`.
- After `useDashboard()` resolves, call `useDashboardDiff(data)` to get `diff`.
- Local state `pendingReward` — set from `diff` when non-zero (XP > 0 or levelDelta > 0 or newBadges.length > 0 or completedMissions.length > 0); cleared on dismiss.
- Mount `<RewardOverlay rewards={pendingReward} onDismiss={...} />` conditionally.
- XPBar: flip `animated={true}` and pass current XP %.

**Edit `apps/student-app/app/(child)/lessons/[lessonId].tsx`:**
- On `submitAnswer.data.isCorrect === false`: trigger QuestionCard shake via a shared `shakeRef` (Reanimated `useSharedValue`).
  - Shake spec: `withSequence(withTiming(-8, {duration:60}), withTiming(8, {duration:60}), withTiming(-4, {duration:60}), withTiming(0, {duration:60}))` on `translateX`.
- On lesson complete (attempt-mutation success): invalidate `useDashboard()` query, then fire `RewardOverlay` with the resulting diff from the refreshed dashboard.
