## Locked decisions (lead, 2026-06-21)
- **Safety = propose-only + human promotion** (authored content never auto-overwritten); **AI questions auto-flagged** out of auto-serve. **Scope = focused slice** (BE-1/2/3/5/6/7; **BE-4 adaptivity-threshold config DEFERRED**).
- **OQ-1** aggregate over **all** `StudentAnswer` rows v1 (revisit completed-only if noisy).
- **OQ-2** `QuestionId` = **real intra-module FK → QuizQuestion (Restrict)** on both new tables (consistent with `StudentAnswer`).
- **OQ-3** enforce one open proposal per question via a **partial unique index** `WHERE "Status" = 1` (Pending).
- **OQ-4** flag shape = **`QuestionQualityState` enum** (`Approved=1, FlaggedForReview=2`) + separate **`FlagReason string?`** for explainability.
- **OQ-5** p-value **0.0–1.0**; config defaults: `MinSamples=30`, `EasyThreshold=0.85`, `HardThreshold=0.45` (Medium between), `AiFlagHighPValue=0.95`, `AiFlagLowPValue=0.20`, divergence = any band mismatch. All in `CalibrationOptions` (config-tunable).
- **OQ-6** store a **stable reason code** (not English prose); localize at read in the BE-5 DTOs (avoids the prior-P5 persisted-string localization debt).
- **OQ-7** AI flag uses **p-value extremes only** (no question-report signal exists today; note as future enhancement).
- **OQ-8** **daily off-peak** config-driven cron (default ~00:20 UTC, after Rec-Recompute 00:05).

## Batches
- **Batch 1 — db-migration (BE-6), blocks everything.** Two new entities (`QuestionDifficultyStats`, `QuestionRecalibrationProposal`) + `QuizQuestion.QualityState` (enum, DB `DEFAULT 1` Approved backfill — mirror P7-05 `LifecycleState`) + `FlagReason text NULL`. New enums `ProposalStatus` (1/2/3) + `QuestionQualityState` (1/2), non-zero start. FKs (Restrict), unique index on `QuestionDifficultyStats.QuestionId`, partial unique `WHERE Status=1` on proposals. DbSets + configs (mirror `StudentRecommendationConfig`). Mirror `20260618142549_AddStudentRecommendation`.
- **Batch 2 — backend-feature BE-1/2/3 (one agent, internally ordered).** `CalibrationOptions` (Domain, config-bound); pure-static `CalibrationEngine` (Application — p-value→band, divergence, AI-flag rules); `ICalibrationService`/`CalibrationService` (Infrastructure, Option C — group-by-QuestionId counts-only aggregation, **never select StudentId**, upsert stats, upsert Pending proposals, set QualityState flag); `CalibrationJob` (mirror `RecommendationRecomputeJob`: IServiceScopeFactory, DisableConcurrentExecution, fail-soft, `SaveChangesAsync(0)`), wired in `LearningModule.InitializeAsync`. **Serve-gate:** add `&& q.QualityState == Approved` to `StartAttemptService.GetPublishedActiveQuestionsAsync` ONLY (not the scoring reads).
- **Batch 3 — backend-feature BE-5.** `CalibrationController` (`api/Learning/Calibration`, AdminOnly): list proposals/flagged (paged), Promote (the ONE human-driven authored-band change) / Reject / Clear-flag / Confirm-flag — all `BaseResponse`/`NewResult`, localized EN+AR (reason codes → localized at read), audited via `AdminActionPerformedDomainEvent`.
- **Batch 4 — gates:** api-tester (10 scenarios incl. the no-PII table/log check) → **security-auditor (BE-7, mandatory: de-identification, admin-only, no destructive overwrite)** → reviewer → committer (PR; HANDOFF in same PR).

- security-auditor PASS (no Critical/High); existing Learning suite green.
