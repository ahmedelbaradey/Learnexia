## Acceptance criteria (verbatim from story)

1. **AC1** — A re-engagement engine evaluates each active child daily and fires at most one nudge per category per day: streak-at-risk (streak active but no qualifying activity yet today), daily-mission reminder, lapse win-back (no session for N days).
2. **AC2** — Triggers are driven by the `P4-01` domain events / streak + mission state — no polling of raw tables in the hot path.
3. **AC3** — Parent controls per child: enable/disable each category, set quiet hours, and a hard daily cap. Defaults are conservative (opt-in friendly) and COPPA-appropriate; the child cannot change them.
4. **AC4** — Delivery is channel-abstracted (push / web push / in-app inbox) so the same engine serves native + PWA; channel availability degrades gracefully.
5. **AC5** — Notification copy is Arabic-first, child-safe, encouraging (never shaming a missed streak), and localizable.
6. **AC6** — Every send/open is logged as an analytics event (P5-03) so re-engagement → return-rate impact is measurable.

Pattern for each (mirrors `UserRegisteredIntegrationEventHandler` shape + adds ReengagementEvaluator + dedupe):
```csharp
public sealed class StreakBrokenIntegrationEventHandler : INotificationHandler<StreakBrokenIntegrationEvent>
{
    // ctor: INotificationsDbContext, IParentChildQuery, IDistributedCache, INudgeDispatcher,
    //       ILoggerManager, ISystemClock, IUserLookup
    public async Task Handle(StreakBrokenIntegrationEvent ev, CancellationToken ct)
    {
        try
        {
            var parentId = await _parentChildQuery.FindParentForChildAsync(ev.StudentId, ct);
            if (parentId is null) { _logger.LogInfo($"P4-09: no parent for student {ev.StudentId}; skip."); return; }

            var prefs = await GetOrDefaultPrefs(ev.StudentId, parentId.Value, NotificationCategory.StreakAtRisk, ct);
            var sentToday = await CountSentToday(ev.StudentId, NotificationCategory.StreakAtRisk, ct);
            var eval = ReengagementEvaluator.Evaluate(prefs, _clock.UtcNow, sentToday, prefs.TimeZoneId);

            if (!eval.Eligible)
            {
                _logger.LogInfo($"analytics.reengagement.not_eligible category=StreakAtRisk childId={ev.StudentId} reason={eval.Reason}");
                return;
            }

            // Redis SETNX dedupe — key uses OccurredOnUtc.Date not wall-clock to handle redelivery
            var dedupeKey = $"nudge:{ev.StudentId}:{(int)NotificationCategory.StreakAtRisk}:{ev.OccurredOnUtc.Date:yyyyMMdd}";
            var acquired = await TryAcquireDedupeAsync(dedupeKey, ct);
            if (!acquired) { _logger.LogInfo($"analytics.reengagement.dedupe_hit category=StreakAtRisk childId={ev.StudentId}"); return; }

            var locale = await GetLocaleAsync(ev.StudentId, ct);
            var (title, body) = ReengagementCopyTemplates.Render(NotificationCategory.StreakAtRisk, locale,
                ("streakLength", ev.PreviousStreak.ToString()));

            var msg = new NudgeMessage(ev.StudentId, parentId.Value, NotificationCategory.StreakAtRisk,
                "STREAK_BROKEN", title, body, dataJson: null,
                ShouldPush: prefs.PushEnabled,
                ShouldInApp: prefs.InAppEnabled);

            await _dispatcher.DispatchAsync(msg, ct);
            _logger.LogInfo($"analytics.reengagement.sent category=StreakAtRisk childId={ev.StudentId}");
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, $"P4-09: StreakBrokenIntegrationEventHandler threw for studentId={ev.StudentId}.");
        }
    }
}
```

Private helpers shared across handlers (either a base class or static helper):
- `GetOrDefaultPrefs(studentId, parentId, category, ct)` — loads `ChildReengagementPreference` row; if absent, returns a new default instance (not persisted).
- `CountSentToday(studentId, category, ct)` — counts `Notification` rows WHERE `RecipientExternalUserId = studentId AND Category = category AND DATE(SentAtUtc) = today_utc` (DB fallback if Redis unavailable).
- `TryAcquireDedupeAsync(key, ct)` — `SetStringAsync(key, "1", options)` with `WhenNotExists = true`; 36h TTL. If Redis throws, log WARN and return `true` (fail-open per D4).
- `GetLocaleAsync(studentId, ct)` — `IUserLookup.FindByIdAsync(studentId)?.PreferredLanguage ?? "ar-EG"`.

**Design note on shared helpers:** The CONVENTIONS rule 8 (ask before patterns) applies here. A private static utility method class (e.g., `ReengagementHandlerHelper`) is NOT a design pattern — it is a simple extraction of repeated procedural code, the same as any private method. No Strategy/Factory/Decorator is involved. This is approved as a direct code reuse, not an abstraction pattern.
