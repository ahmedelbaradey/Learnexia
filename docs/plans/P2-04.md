## Lead decisions resolved (do NOT re-raise)

| # | Decision |
|---|---|
| Q1 | **Unlock formula = AND.** A lesson is `Available` iff ALL `Prerequisite`-typed `KnowledgeEdge`s whose `TargetNode.SkillId == lesson.SkillId` resolve to mastered. `Strength` field is ignored in v1. |
| Q2 | **Mastery definition.** A skill is Mastered for a student iff `AccuracyPercentage >= Skill.MasteryThreshold` AND `TotalAnswers >= 1`. `MasteryThreshold` is an `int 0..100` (confirmed: seeded values 70/75/80/85). |
| Q3 | **Lessons with `SkillId IS NULL` → `Available` by default.** No skill to gate on; they are fill-in content. |
| Q4 | **Lessons whose skill has zero Prerequisite inbound edges → `Available` by default.** Root nodes in the graph are entry points. |
| Q5 | **`Completed` = at least one `Attempt` with `StudentId == studentId AND LessonId == lessonId AND Status == AttemptStatus.Completed`.** Accuracy on the attempt is NOT a gating condition for `Completed`; accuracy gates mastery (Q2), a separate concept. |
| Q6 | **Engine shape = pure static class** `LearningPathEngine` at `Learning.Domain/Services/LearningPathEngine.cs`, mirroring `SkillGraphValidator`. No DI, no DB inside the engine; caller pre-fetches all inputs. |
| Q7 | **LEAD CHOSE OPTION A.** Extend the existing `GetSubjectSkillTreeQuery` and `GetSubjectLessonsQuery` handlers. The `studentId` is sourced from `_currentUser.UserId` (IDOR-proof — never from route or query-string). When the request is **authenticated** (JWT present), run the engine. **Add `[Authorize]` to both `Subjects/{id}/SkillTree` AND `Subjects/{id}/Lessons` actions** — this is the P2-02 deferred hardening. `GetSubjectsForGrade` stays anonymous (grade browsing). **BREAKING CHANGE:** any caller of these two endpoints without a JWT will begin receiving 401. Document in HANDOFF. |
| Q8 | **Bulk, not per-lesson.** Engine is called once per subject per request — 3 bulk repository queries + in-memory compute. |
| Q9 | **Explainability shape.** Per locked lesson: `MissingPrerequisites: List<MissingPrerequisiteDto>` where each item = `{ PrereqSkillId, PrereqSkillName, PrereqNodeId, RequiredAccuracy, CurrentAccuracy }`. Immediate prereqs only; no transitive closure. Empty list when `Available` or `Completed`. |
| Q10 | **Cycle defense via visited-set memoization.** A `HashSet<int>` (or `Dictionary<int,bool>`) of visited node IDs per traversal ensures the engine does NOT infinite-loop even if a cycle bypasses `SkillGraphValidator` at seed time. |
| Q11 | **Three new `ILearningRepository` bulk-fetch methods** (not the Q11 brief signatures — the lead-approved signatures are listed in the Task Inventory below). |
| IsLocked fate | **Keep `Lesson.IsLocked` column for one wave.** Mark the property `[Obsolete("Replaced by LearningPathEngine in P2-04. Will be removed in P2-09 or P6-06.")]`. Engines do NOT read `Lesson.IsLocked` anywhere. |

##### `backend/src/Modules/Learning/Learnexia.Modules.Learning.Domain/Services/LearningPathEngine.cs` (NEW)

Key design constraints:
- **Static class only** — no DI, no DB, no instance state.
- Mirrors `SkillGraphValidator` shape (static class, one public entry point, private helpers).
- Caller pre-fetches ALL inputs; engine is pure computation.
- Cycle defense: `HashSet<int> visited` per DFS call (memoization, not recursion-stack coloring — the engine skips already-computed nodes rather than detecting cycles via back-edge; this is sufficient because `ComputeSkillState` for a visited node returns its memoized result).
- No `SaveChangesAsync` — engine is read-only.
- No design patterns (no Strategy/Visitor/Factory) — plain static helpers only.

```csharp
using System.Diagnostics;
using Learnexia.Modules.Learning.Domain.Entities;
using Learnexia.Modules.Learning.Domain.Enums;

namespace Learnexia.Modules.Learning.Domain.Services;

/// <summary>
/// Deterministic, reproducible learning path engine. Computes per-lesson <see cref="NodeState"/>
/// and missing-prerequisite explanations for a student in a subject.
///
/// CONTRACT:
/// - Pure static — no database, no DI. Caller pre-fetches all inputs.
/// - Called once per subject per request (bulk, not per-lesson).
/// - <see cref="SkillMastery.AccuracyPercentage"/> and <see cref="Skill.MasteryThreshold"/> share
///   the same scale: both are 0..100 representing a percentage.
/// - Thread-safe (no shared mutable state).
/// </summary>
public static class LearningPathEngine
{
    /// <summary>
    /// Computes the unlock state for every lesson in <paramref name="lessons"/>.
    /// </summary>
    /// <param name="nodes">All KnowledgeNodes for the subject.</param>
    /// <param name="edges">All KnowledgeEdges for the subject (Prerequisite and Related).</param>
    /// <param name="masteryBySkillId">
    ///     Pre-aggregated per-skill mastery for this student. Skills absent from the dict = zero answers.
    /// </param>
    /// <param name="completedLessonIds">
    ///     Set of lessonIds where the student has at least one Attempt with Status == Completed.
    /// </param>
    /// <param name="lessons">All lessons for the subject (must include SkillId, Id).</param>
    /// <param name="skillsById">
    ///     Lookup of Skill by Id, needed for MasteryThreshold + Name on each prerequisite skill.
    /// </param>
    /// <returns>
    ///     Dictionary keyed by LessonId containing the computed <see cref="LessonUnlockStateDto"/>.
    /// </returns>
    public static IReadOnlyDictionary<int, LessonUnlockStateDto> ComputeStates(
        IReadOnlyList<KnowledgeNode> nodes,
        IReadOnlyList<KnowledgeEdge> edges,
        IReadOnlyDictionary<int, SkillMastery> masteryBySkillId,
        IReadOnlySet<int> completedLessonIds,
        IReadOnlyList<Lesson> lessons,
        IReadOnlyDictionary<int, Skill> skillsById)
    {
        // MasteryThreshold contract guard (defense-in-depth; never fires on seeded data)
        Debug.Assert(skillsById.Values.All(s => s.MasteryThreshold >= 0 && s.MasteryThreshold <= 100),
            "Skill.MasteryThreshold must be in the range 0..100 (percentage).");

        // Build lookup: SkillId -> KnowledgeNode (for skills that have a node)
        var nodeBySkillId = nodes
            .Where(n => n.SkillId.HasValue)
            .ToDictionary(n => n.SkillId!.Value, n => n);

        // Build adjacency: targetNodeId -> list of source (prerequisite) nodes
        // Only Prerequisite-typed edges participate in unlock rules (Q1).
        var prereqSourcesByTargetNodeId = edges
            .Where(e => e.RelationshipType == EdgeRelationshipType.Prerequisite)
            .GroupBy(e => e.TargetNodeId)
            .ToDictionary(
                g => g.Key,
                g => g.Select(e => e.SourceNodeId).ToList());

        // Memoized skill mastery state (nodeId -> bool: is the skill wrapped by this node mastered?)
        // Prevents redundant computation and breaks any cycle that bypassed seed-time validation.
        var masteryMemo = new Dictionary<int, bool>();

        var result = new Dictionary<int, LessonUnlockStateDto>(lessons.Count);

        foreach (var lesson in lessons)
        {
            // Rule Q5: Completed wins over all other state.
            if (completedLessonIds.Contains(lesson.Id))
            {
                result[lesson.Id] = new LessonUnlockStateDto(lesson.Id, NodeState.Completed,
                    Array.Empty<MissingPrerequisiteDto>());
                continue;
            }

            // Rule Q3: Lesson with no linked skill is always Available.
            if (lesson.SkillId is null)
            {
                result[lesson.Id] = new LessonUnlockStateDto(lesson.Id, NodeState.Available,
                    Array.Empty<MissingPrerequisiteDto>());
                continue;
            }

            var skillId = lesson.SkillId.Value;

            // Rule Q4: If the skill has no KnowledgeNode (never mapped), treat as root → Available.
            if (!nodeBySkillId.TryGetValue(skillId, out var node))
            {
                result[lesson.Id] = new LessonUnlockStateDto(lesson.Id, NodeState.Available,
                    Array.Empty<MissingPrerequisiteDto>());
                continue;
            }

            // Rule Q4: If this node has no inbound Prerequisite edges, it is a root → Available.
            if (!prereqSourcesByTargetNodeId.TryGetValue(node.Id, out var prereqSourceNodeIds)
                || prereqSourceNodeIds.Count == 0)
            {
                result[lesson.Id] = new LessonUnlockStateDto(lesson.Id, NodeState.Available,
                    Array.Empty<MissingPrerequisiteDto>());
                continue;
            }

            // All prereqs must be mastered (Q1 — AND logic). Collect unmet ones for AC3.
            var missing = new List<MissingPrerequisiteDto>();

            foreach (var prereqNodeId in prereqSourceNodeIds)
            {
                // Cycle defense: if this node is already in computation (memoization covers it),
                // skip it — we treat unmemoized back-edges as "not mastered" (safe default).
                var prereqNode = nodes.FirstOrDefault(n => n.Id == prereqNodeId);
                if (prereqNode is null) continue;

                var prereqIsMastered = IsNodeMastered(
                    prereqNode,
                    masteryBySkillId,
                    skillsById,
                    masteryMemo);

                if (!prereqIsMastered)
                {
                    // Build MissingPrerequisiteDto (Q9)
                    var prereqSkillId = prereqNode.SkillId;
                    if (prereqSkillId.HasValue && skillsById.TryGetValue(prereqSkillId.Value, out var prereqSkill))
                    {
                        var currentAccuracy = masteryBySkillId.TryGetValue(prereqSkillId.Value, out var sm)
                            ? sm.AccuracyPercentage : 0.0;

                        missing.Add(new MissingPrerequisiteDto(
                            PrereqSkillId: prereqSkillId.Value,
                            PrereqSkillName: prereqSkill.Name,
                            PrereqNodeId: prereqNodeId,
                            RequiredAccuracy: prereqSkill.MasteryThreshold,
                            CurrentAccuracy: currentAccuracy));
                    }
                    else
                    {
                        // Prereq node wraps no skill (concept/review node) — treat as unmet placeholder
                        missing.Add(new MissingPrerequisiteDto(
                            PrereqSkillId: 0,
                            PrereqSkillName: prereqNode.Name,
                            PrereqNodeId: prereqNodeId,
                            RequiredAccuracy: 100,
                            CurrentAccuracy: 0.0));
                    }
                }
            }

            var state = missing.Count == 0 ? NodeState.Available : NodeState.Locked;
            result[lesson.Id] = new LessonUnlockStateDto(lesson.Id, state,
                missing.Count > 0 ? missing : Array.Empty<MissingPrerequisiteDto>());
        }

        return result;
    }

    /// <summary>
    /// Returns true if the skill wrapped by <paramref name="node"/> is mastered for the student.
    /// Uses <paramref name="memo"/> to avoid re-computation and prevent infinite loops on cycles.
    /// </summary>
    private static bool IsNodeMastered(
        KnowledgeNode node,
        IReadOnlyDictionary<int, SkillMastery> masteryBySkillId,
        IReadOnlyDictionary<int, Skill> skillsById,
        Dictionary<int, bool> memo)
    {
        if (memo.TryGetValue(node.Id, out var cached)) return cached;

        // Sentinel: mark as "not mastered" before computing to break cycles.
        memo[node.Id] = false;

        if (!node.SkillId.HasValue)
        {
            // Non-skill node (concept/review): treat as not mastered for unlock purposes.
            memo[node.Id] = false;
            return false;
        }

        var skillId = node.SkillId.Value;
        if (!skillsById.TryGetValue(skillId, out var skill))
        {
            memo[node.Id] = false;
            return false;
        }

        if (!masteryBySkillId.TryGetValue(skillId, out var mastery))
        {
            // No answers at all → TotalAnswers == 0 → not mastered (Q2 guard).
            memo[node.Id] = false;
            return false;
        }

        // Q2: mastered iff AccuracyPercentage >= MasteryThreshold AND TotalAnswers >= 1
        var mastered = mastery.TotalAnswers >= 1
                    && mastery.AccuracyPercentage >= skill.MasteryThreshold;

        memo[node.Id] = mastered;
        return mastered;
    }
}
```
