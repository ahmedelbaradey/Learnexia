### Batch 2 — PARALLEL — `backend-feature` agent (two threads)

#### Batch 2a — BE-2 (SpacedRepetitionOptions)

**Files (NEW):**
- `Learning.Application/Options/SpacedRepetitionOptions.cs` — POCO bound from `SpacedRepetition:Engine` config section: `int[] IntervalLadderDays = [1, 3, 7, 14, 30]`, `int NeedsReviewIntervalDays = 1`, `string JobCronExpression = "0 0 * * *"`.
- `appsettings.json` — add `SpacedRepetition:Engine` section.

**SM-2 flag:** `EaseFactor` and SM-2 algorithm are explicitly flagged as a deferred upgrade. Do NOT implement. If the implementer reaches for SM-2, stop and ask the lead.

#### Batch 2b — BE-3 (SpacedRepetitionEngine + unit tests)

**Files (NEW):**
- `Learning.Domain/Services/SpacedRepetitionEngine.cs` — pure static class:
  - `ComputeNextReview(int repetitionNumber, bool improved, SpacedRepetitionOptions options) → (int nextIntervalDays, int nextRepetitionNumber)`: if `improved`, advance ladder index (clamp at max); if not improved, reset to index 0.
  - `IsDue(MasteryStatus status, DateTime? nextReviewDueAt, DateTime utcNow) → bool`: due if `status == NeedsReview` OR (`status == Mastered` AND `nextReviewDueAt.HasValue && utcNow >= nextReviewDueAt.Value`). All `DateTime` values must be UTC — assert or document.
- `tests/Modules.Learning.UnitTests/SpacedRepetitionEngineTests.cs` — 7+ cases: ladder advance (repetition 0→1, 1→2, capped at max); failure resets to index 0; IsDue for NeedsReview (always due); IsDue for Mastered+past due date (due); IsDue for Mastered+future due date (not due); IsDue for NotStarted (not due); idempotency (same inputs → same output).

**Completion gate:** Build green; 7+ engine unit tests pass; engine is plain static.

### Batch 3 — SEQUENTIAL — `backend-feature` agent — BE-4

**Depends on:** Batch 2 (both) complete AND Batch 1 complete.

**Files (EDIT):**
- `ILearningRepository.cs` — add `GetDueMasteryRowsAsync(DateTime utcNow, CancellationToken ct)` (returns `IReadOnlyList<StudentSkillMastery>` where `IsDue` per engine rules — status NeedsReview OR Mastered+NextReviewDueAt past); `UpdateSpacedRepetitionFieldsAsync(int id, int intervalDays, int repetitionNumber, DateTime nextDueAt, CancellationToken ct)` (targeted update for interval progression, no full row reload).
- `LearningRepository.cs` — implement both with UTC-disciplined queries. `GetDueMasteryRowsAsync`: query `StudentSkillMastery WHERE (Status=NeedsReview) OR (Status=Mastered AND NextReviewDueAt <= utcNow)`. Use `AsNoTracking()` for reads. Note UTC `Kind` consistency (see HANDOFF P2-08 UTC-quirk).

**Completion gate:** Build green; interface + implementation compile; UTC handling confirmed.

#### Batch 4a — BE-5 (SpacedRepetitionSweepJob + DI)

**Files (NEW):**
- `Learning.Infrastructure/Jobs/SpacedRepetitionSweepJob.cs` — implements `IJob` (Hangfire): loads all due mastery rows via `GetDueMasteryRowsAsync(DateTime.UtcNow)`, for mastered-but-stale rows recomputes `NextReviewDueAt = LastPracticedAt + TimeSpan.FromDays(currentIntervalDays)` (pure recompute — idempotent), calls `UpdateSpacedRepetitionFieldsAsync`; **does not advance the ladder** (that is BE-6's completion-hook job); only ensures `NextReviewDueAt` is correct per current `RepetitionNumber`.

**File (EDIT):** Learning DI extension — `RecurringJob.AddOrUpdate<SpacedRepetitionSweepJob>("SR-Sweep", j => j.Execute(), Cron.Daily())` using `SpacedRepetitionOptions.JobCronExpression`.

#### Batch 4b — BE-6 (Completion hook in CompleteAttemptCommandHandler)

**File (EDIT):** `Application/Features/Attempts/Commands/CompleteAttempt/CompleteAttemptCommandHandler.cs`

After P3-09's mastery upsert (inside the same explicit transaction), for each skill touched: if a `StudentSkillMastery` row exists and `IsDue(status, nextReviewDueAt, UtcNow)` was true before this attempt, call `SpacedRepetitionEngine.ComputeNextReview(row.RepetitionNumber, improved: newStatus != NeedsReview, options)` and write back `ReviewIntervalDays`, `RepetitionNumber`, `NextReviewDueAt = UtcNow + TimeSpan.FromDays(nextIntervalDays)`. If not due (routine practice), skip interval update.

#### Batch 4c — BE-7 (Due-list query + endpoint)

**Files (NEW):**
- `Application/Features/Reviews/Queries/GetDueReviews/` — query + handler; fetches due rows for `ICurrentUserService.UserId` via `GetDueMasteryRowsAsync(DateTime.UtcNow)` filtered to the student's `StudentId`; joins with `Skill` entity for `Name`; returns `IReadOnlyList<DueReviewDto>` (`SkillId`, `SkillName`, `NextReviewDueAt`, `Status`, `RepetitionNumber`).
- `Api/Controllers/ReviewsController.cs` — `[Authorize(Roles="Student")]`; `GET /api/Learning/Reviews/Due`; `studentId` from `ICurrentUserService.UserId` only.

**Files (EDIT):** `SharedResourcesKey.cs`, `SharedResources.en-US.resx`, `SharedResources.ar-EG.resx` — key: `DueReviewsRetrievedSuccessfully`.

**Completion gate (each thread):** Build green; job registered; completion hook UTC-disciplined; due-list endpoint functional.
