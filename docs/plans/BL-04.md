**Agent:** `db-migration`
**Mode:** Sequential (each step depends on the previous)
**Condition:** BE-1 only if lead chose option A (new `curriculum` module). Skip BE-1 for option B.

**Shared-file serialization constraints:**
- `Directory.Packages.props` (BE-2) — serialize with any concurrent story edits.
- `Program.cs` (BE-1, option A) — serialize with any concurrent story that touches it.

### Batch 3 — SEQUENTIAL — `reviewer` gate, then `committer`

4. AC-4: Migration applies cleanly; pgvector extension enabled before table creation.

9. ANN index (HNSW/IVFFlat) deliberately NOT present — deferred to BL-05/P3-07. Reviewer confirms this is intentional.
10. `docs/dev/HANDOFF.md` updated with: module decision outcome, dimension chosen, schema location, pgvector package versions, note that BL-01/02/05/03 depend on this.
