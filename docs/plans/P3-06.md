## Execution batches

### Batch 1 — SEQUENTIAL — `backend-feature` agent — BE-1 then BE-2

**Agent:** `backend-feature`
**Mode:** Sequential (BE-2 depends on BE-1)
**Shared-file warning:** BE-1 touches `Shared.Contracts` — serialize against any concurrent story editing this package.

BE-1 — `IChunkRetrievalContract` in `Shared.Contracts/Curriculum/`:
```csharp
// Shared.Contracts/Curriculum/IChunkRetrievalContract.cs
public interface IChunkRetrievalContract
{
    Task<RetrievalResult> RetrieveAsync(
        string text, int gradeId, int subjectId, int? skillId, int topK,
        CancellationToken ct = default);
}

// Shared.Contracts/Curriculum/RetrievalResult.cs
public record RetrievalResult(IReadOnlyList<ChunkDto> Chunks);

// Shared.Contracts/Curriculum/ChunkDto.cs
public record ChunkDto(string Content, string Metadata, double Score);
```
`Chunks` is empty when nothing clears the similarity floor — the unambiguous no-grounding signal.

BE-2 — `ChunkRetrievalContractAdapter` in `Curriculum.Infrastructure/Contracts/`:
- Implements `IChunkRetrievalContract` by dispatching `RetrieveChunksQuery` through MediatR (or a direct service call within the Curriculum module, if in-process).
- Registered in `AddCurriculumInfrastructure` as `IChunkRetrievalContract → ChunkRetrievalContractAdapter` (scoped).

**Gate after Batch 1:** `dotnet build` green; `IChunkRetrievalContract` is visible to Learning.Application (via `Shared.Contracts` reference — no direct Curriculum project reference).

### Batch 2 — SEQUENTIAL — `backend-feature` agent — BE-3 then BE-4

**Agent:** `backend-feature`
**Mode:** Sequential (BE-4 depends on BE-3)

BE-3 — Command + validator + result model:
- `GenerateGroundedQuestionsCommand : ICommand<BaseResponse<GeneratedQuestionsResult>>` — `{ SkillId?, LessonId?, GradeId, Count, QuestionType[] Types }`.
- `GenerateGroundedQuestionsCommandValidator` — at least one of SkillId/LessonId required; `GradeId > 0`; `Count` 1..20 (abuse bound); `Types` not empty; reject `QuestionType.Matching` per OQ-4 (validator returns a clear error: "Matching-type generation is deferred until CO-BE-1 lands").
- `GeneratedQuestionsResult` — `{ GenerationStatus Status, IReadOnlyList<GeneratedQuestionDto> Questions }` where `Status: Generated | Declined_NoContext | Declined_AllFailedSafety`.
- `GeneratedQuestionDto` — mirrors `QuizQuestion` shape: `QuestionType`, `Content`, `Options`, `CorrectAnswer`, `Difficulty`.

BE-4 — `GenerateGroundedQuestionsCommandHandler` — orchestration (sequential, fail-soft at each AI boundary):

1. **Retrieve** — call `IChunkRetrievalContract.RetrieveAsync(text=concept/skill name, gradeId, subjectId derived from skill/lesson context, skillId, topK=5)`.
   - **If `Chunks.Count == 0` → return `BaseResponse.Success(new GeneratedQuestionsResult(Declined_NoContext, []))` immediately. No LLM call, no write. (AC-4 — HARD CRITERION.)**

2. **Build prompt** — call P3-03 Prompt Builder with generate template: inject grade/age/language, curriculum chunks as context, child-safe tone, per-subject question-generation template, instruct strict JSON output for `Types` (OQ-3).

3. **Generate** — call P3-01 Gateway structured-output. Parse JSON into `GeneratedQuestionDto[]`. Bounded retry (≤ 3) on parse failure.

4. **Validate** — reuse `QuizQuestionTypeValidation` per item + `AnswerComparator` shape check (the CorrectAnswer must be in the shape the comparator expects for the type). Invalid → regenerate (up to bound) or drop. Never persist a malformed item.

5. **Safety** — pass every surviving item through P3-02 Safety Layer. Failures blocked; blocked items logged via `ILoggerManager`. If ALL items fail safety → return `Declined_AllFailedSafety`.

6. **Persist** — valid+safe items as `QuizQuestion` (`GeneratedBy = AI`, `LifecycleState` per OQ-5). If `Count > 1`, open an explicit `BeginTransactionAsync` / commit (no UoW).

7. Return `BaseResponse.Success(new GeneratedQuestionsResult(Generated, savedItems))`.

Inject: `IChunkRetrievalContract`, P3-03 prompt builder, P3-01 gateway client, P3-02 safety client, `ILearningRepositoryManager`, `ILoggerManager`.

**Gate after Batch 2:** `dotnet build` green; handler compiles with stubbed dependencies.

### Batch 4 — SEQUENTIAL — `api-tester` agent

**Depends on:** Batch 3 complete. Requires stubbed P3-01 gateway + P3-02 safety (do not hit live LLMs in CI).
**Agent:** `api-tester`

Required test cases (stubbed gateway/safety for determinism):
1. **Grounded generation happy path:** seed a skill with matching curriculum chunks → `POST /api/Learning/AIGeneration/GenerateQuestions` with valid `SkillId + GradeId + Count=2 + Types=[MCQ]` → HTTP 200, `Successed=true`, `Status=Generated`, 1–2 `QuizQuestion` rows written with `GeneratedBy=AI`, `LifecycleState` per OQ-5. Validate shape: `CorrectAnswer` passes `AnswerComparator` check.
2. **EMPTY-RETRIEVAL DECLINE (headline AC-4):** a skill/grade combo with no seeded chunks → same request → HTTP 200, `Successed=true`, `Status=Declined_NoContext`, zero `QuizQuestion` rows written, no LLM call made (assert stub gateway not invoked).
3. **Safety block:** stub safety layer to block all items → `Status=Declined_AllFailedSafety`, zero rows written, block event logged.
4. **Malformed LLM output:** stub gateway returns invalid JSON → no item persisted; bounded retry count exhausted; response `Status=Generated` with 0 items (or `Declined_AllFailedSafety` if all parse failures count as failures — confirm policy).
5. **Matching type rejected:** `Types=[Matching]` → HTTP 400, validation error (not a 500).
6. **Unauthenticated / wrong role:** no bearer or non-admin JWT → 401/403.
7. **Envelope:** all responses carry `Successed` (capital S), camelCase JSON.

### Batch 5 — `security-auditor` (HARD GATE)

**Depends on:** Batch 3 complete.
**Agent:** `security-auditor`

This story generates AI content potentially shown to children — **security-auditor is a hard gate; Critical/High findings block.**

Audit:
- **No Safety-Layer bypass (AC-3):** there is literally no code path that persists/returns a generated question without calling P3-02. Trace all code paths through the handler.
- **Decline-on-empty enforced (AC-4):** verify no fallback, default branch, or exception handler calls the LLM when `Chunks.Count == 0`.
- **Prompt-injection resistance:** retrieved chunks + any skill context parameter can't smuggle instructions that subvert the generation or safety prompt (OQ-3 structured output reduces risk).
- **Cost/abuse bounds:** `Count` max enforced by validator; retry loop bounded (≤ 3 per item); `TopK` not unbounded.
- **No secret/key leakage:** gateway/safety adapter logs must not include API keys.
- **`GeneratedBy.AI` tag always set** on persisted items — no untagged AI content.
