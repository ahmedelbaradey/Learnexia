## Lead decisions applied

1. **Q1 — Grade:** modeled as a **separate `Grade` entity** with relationships (NOT an int column on Subject). `Subject` has `GradeId` FK → `Grade`. `Grade` carries `Number` (int 1–6) and `DisplayName` (string).
2. **Q3 — Difficulty:** `Difficulty` (on `Lesson`) and `DifficultyLevel` (on `Concept`) are **C# enums** (`DifficultyLevel { Easy = 1, Medium = 2, Hard = 3 }`) stored as `int` via `HasConversion<int>`. Subject/Unit/Lesson/Concept/Skill `Name` stay `string` (admin-authored curriculum content).
3. **Q7 — Scope:** full vertical slice — Model + EF config + migration + CQRS commands/queries + controllers/endpoints. Because HTTP endpoints are exposed, **`api-tester` runs after `backend-feature`**.
4. **Remaining brief defaults applied:**
   - `Subject.Country` nullable, `Concept.Description` nullable.
   - FK delete behavior: **Restrict** on all required FK chains (Grade→Subject, Subject→Unit, Unit→Lesson, Subject→Concept, Concept→Skill). Optional `Lesson.SkillId`: **SetNull** on delete.
   - Catalog stays untouched (additive-only; retirement is a later story).
   - No startup auto-migrate required for non-Identity modules; `LearningModule.InitializeAsync` calls `MigrateAsync` (mirror CatalogModule pattern).

## Blockers / prerequisites

1. **P1-06 already satisfied.** PostgreSQL + Npgsql are in place. No blocker.
2. **Shared-file serialization.** The five shared files (`Learnexia.Modular.sln`, `Program.cs`, `MediatRExtensions.cs`, `Claims.cs`, Host `csproj`) must be edited by exactly one story at a time. P2-01 is the Phase-2 foundation and should be the **first** Phase-2 story to touch these files. The lead must confirm no parallel Phase-2 sibling is currently in Batch 4 of its own pipeline.
3. **`AggregateRoot` base exists** in `Shared.Kernel` — confirmed. No shared-kernel changes needed.
4. **`IDomainEventDispatcher` / `InProcessDomainEventDispatcher` exist** — confirmed (used by Identity's UoW behavior). No new registration needed.
5. **`Directory.Packages.props`** — no change required. All needed NuGet packages (EF Core 10, Npgsql 10, MediatR, FluentValidation, AutoMapper) are already centrally versioned.
6. **Grade entity is new** (lead decision Q1 overrides brief's "int column" assumption). The `db-migration` agent must create the `Grade` table and `Subject.GradeId` FK; the `backend-feature` agent must add `IGradeService` and `GradesController`. This is a confirmed in-scope addition.
7. **No security-auditor stage.** P2-01 has no auth/authz enforcement, no child data writes, no file upload, no AI/secrets/payments surface. The reviewer checks that `[Authorize]` is deliberately absent (not accidentally omitted).
8. **No designer stage.** Backend-only story; no UI surface.
