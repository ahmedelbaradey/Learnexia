## Acceptance criteria (verbatim from story)

1. **AC1** — Students are grouped into leagues (Bronze → Silver → Gold → Diamond) and ranked by weekly XP.
2. **AC2** — A weekly background job promotes top performers and demotes the bottom per tier rules.
3. **AC3** — The league standings are visible with the student's current position.
4. **AC4** — The promotion/demotion job is idempotent and runs reliably on schedule.

### B0-1 — Refactor `StudentXpProfile.ApplyAward` + introduce `XpAwardedDomainEvent`

**Critical finding from source:**
- `ApplyAward(int amount, int newLevel)` — 2-arg signature today (line 115).
- `RecordBadgeEarned(...)` mutates `TotalXp += rewardXp` directly (line 290-291), bypasses `ApplyAward`.
- `RecordMissionCompleted(...)` mutates `TotalXp += rewardXp` directly (line 328-329), bypasses `ApplyAward`.
- 5 command handler call sites: `AwardLessonCompletedXpCommandHandler` (2 calls), `AdvanceStreakCommandHandler` (1), `AwardAnswerSubmittedXpCommandHandler` (1), `AwardBadgeCommandHandler` (via `RecordBadgeEarned`), `IncrementMissionProgressCommandHandler` (via `RecordMissionCompleted`).

**Step 1 — Create `XpAwardedDomainEvent.cs`** at `Gamification.Domain/Events/`:

```csharp
public sealed record XpAwardedDomainEvent(
    int StudentId,
    int Amount,
    int TotalXpAfter,
    XpReason Reason,
    DateTime OccurredAtUtc) : IDomainEvent
{
    public Guid EventId { get; } = Guid.NewGuid();
    public DateTime OccurredOnUtc { get; } = DateTime.UtcNow;
}
```

**Step 2 — Refactor `ApplyAward` to 4-arg signature:**

```csharp
public void ApplyAward(int amount, int newLevel, XpReason reason, DateTime occurredAtUtc)
{
    var oldLevel = CurrentLevel;
    TotalXp += amount;
    CurrentLevel = newLevel;
    LastAwardAtUtc = occurredAtUtc;       // use event time, not wall-clock

    // Always raise — every XP increment fans out to XpAwardedLeagueHandler (P4-07).
    RaiseDomainEvent(new XpAwardedDomainEvent(StudentId, amount, TotalXp, reason, occurredAtUtc));

    if (newLevel > oldLevel)
        RaiseDomainEvent(new StudentLeveledUpDomainEvent(StudentId, oldLevel, newLevel));
}
```

Note: `LastAwardAtUtc` now stores `occurredAtUtc` (event time) rather than `DateTime.UtcNow` (wall-clock). This is a load-bearing semantic improvement — ensures the ledger records the event's own timestamp, not the processing timestamp.

**Step 3 — Refactor `RecordBadgeEarned` to call `ApplyAward`:**

```csharp
public void RecordBadgeEarned(
    int badgeDefinitionId,
    string code,
    BadgeRarity rarity,
    int rewardXp,
    int newLevel,
    DateTime awardedAtUtc)
{
    // Delegate XP mutation + XpAwardedDomainEvent + optional level-up event to chokepoint.
    ApplyAward(rewardXp, newLevel, XpReason.BadgeEarned, awardedAtUtc);

    // Badge-specific event raised AFTER ApplyAward (XpAwardedDomainEvent dispatched first).
    RaiseDomainEvent(new BadgeEarnedDomainEvent(
        StudentId,
        badgeDefinitionId,
        code,
        rarity,
        rewardXp,
        awardedAtUtc));
}
```

**Step 4 — Refactor `RecordMissionCompleted` to call `ApplyAward`:**

```csharp
public static class LeagueStandings
{
    public readonly record struct PromotionPlan(int PromoteCount, int DemoteCount, int StayCount);

    /// <summary>
    /// Computes how many members promote, demote, and stay for a cohort of the given size at
    /// the given tier. Handles tier extremes (Diamond top-N stay; Bronze bottom-N stay) and
    /// small cohort scaling.
    /// </summary>
    /// <param name="cohortSize">Actual member count (≥1).</param>
    /// <param name="currentTier">The tier this cohort competes in.</param>
    /// <param name="basePromoteCount">From LeagueOptions.PromoteCount (default 7).</param>
    /// <param name="baseDemoteCount">From LeagueOptions.DemoteCount (default 5).</param>
    public static PromotionPlan ComputeCutoffs(
        int cohortSize,
        LeagueTier currentTier,
        int basePromoteCount = 7,
        int baseDemoteCount = 5)
    {
        int promoteN, demoteN;

        if (cohortSize < 12)
        {
            // Small cohort: scale proportionally; minimum 0 (not 1) to allow all-stay edge case
            promoteN = (int)Math.Floor(cohortSize * 7.0 / 30);
            demoteN  = (int)Math.Floor(cohortSize * 5.0 / 30);
        }
        else
        {
            promoteN = basePromoteCount;
            demoteN  = baseDemoteCount;
        }

        // Tier extremes: cap at 0 where movement is impossible
        if (currentTier == LeagueTier.Diamond) promoteN = 0;  // nowhere up
        if (currentTier == LeagueTier.Bronze)  demoteN  = 0;  // nowhere down

        int stayN = Math.Max(0, cohortSize - promoteN - demoteN);
        return new PromotionPlan(promoteN, demoteN, stayN);
    }

    /// <summary>
    /// Assigns MembershipStatus to each member. Input list MUST be pre-sorted
    /// DESC by WeeklyXp then ASC by JoinedAtUtc (tiebreak).
    /// Returns (MembershipId, FinalRank, TierAfter, Status) per member.
    /// </summary>
    public static IReadOnlyList<(int MembershipId, int FinalRank, LeagueTier TierAfter, MembershipStatus Status)>
        Apply(
            IReadOnlyList<LeagueMembership> ranked,
            LeagueTier currentTier,
            int basePromoteCount = 7,
            int baseDemoteCount = 5)
    {
        var plan = ComputeCutoffs(ranked.Count, currentTier, basePromoteCount, baseDemoteCount);
        var results = new List<(int, int, LeagueTier, MembershipStatus)>(ranked.Count);

        for (int i = 0; i < ranked.Count; i++)
        {
            int rank = i + 1;
            MembershipStatus status;
            LeagueTier tierAfter;

            if (i < plan.PromoteCount && currentTier != LeagueTier.Diamond)
            {
                status   = MembershipStatus.Promoted;
                tierAfter = (LeagueTier)((int)currentTier + 1);
            }
            else if (i >= ranked.Count - plan.DemoteCount && plan.DemoteCount > 0
                     && currentTier != LeagueTier.Bronze)
            {
                status   = MembershipStatus.Demoted;
                tierAfter = (LeagueTier)((int)currentTier - 1);
            }
            else
            {
                status   = MembershipStatus.Stayed;
                tierAfter = currentTier;
            }

            results.Add((ranked[i].Id, rank, tierAfter, status));
        }

        return results;
    }
}
```

/// <summary>
/// Pure static helper for first-fit league cohort assignment.
/// No DB access — takes pre-loaded cohort data, returns the chosen or created League.
/// Unit-testable in isolation (mirrors LeagueStandings pattern).
/// </summary>
public static class LeaguePlacementService
{
    /// <summary>
    /// Finds the first existing cohort at (tier, periodKey) with available capacity,
    /// OR creates a new League value with GroupIndex = maxExisting + 1.
    /// </summary>
    /// <param name="tier">The student's current tier.</param>
    /// <param name="periodKey">Current week period key (e.g., "W:2026-23").</param>
    /// <param name="periodStartUtc">Monday 00:00 UTC of the period.</param>
    /// <param name="periodEndUtc">Next Monday 00:00 UTC of the period.</param>
    /// <param name="existingCohorts">All League rows at (tier, periodKey). May be empty.</param>
    /// <param name="participantCounts">Map of LeagueId → participant count.</param>
    /// <param name="capacity">Cohort capacity from LeagueOptions.CohortSize.</param>
    /// <returns>
    /// (league: the chosen or created League, createdNew: true if a new League was returned).
    /// If createdNew is true, the caller must persist the League before inserting the membership.
    /// </returns>
    public static (League League, bool CreatedNew) FindOrCreateCohort(
        LeagueTier tier,
        string periodKey,
        DateTime periodStartUtc,
        DateTime periodEndUtc,
        IReadOnlyList<League> existingCohorts,
        IReadOnlyDictionary<int, int> participantCounts,
        int capacity)
    {
        // First-fit: find the first cohort with < capacity members.
        foreach (var cohort in existingCohorts.OrderBy(c => c.GroupIndex))
        {
            var count = participantCounts.GetValueOrDefault(cohort.Id, 0);
            if (count < capacity)
                return (cohort, false);
        }

        // All full (or no cohorts): create a new one.
        int nextGroupIndex = existingCohorts.Count == 0
            ? 1
            : existingCohorts.Max(c => c.GroupIndex) + 1;

        var newLeague = League.Create(tier, periodKey, periodStartUtc, periodEndUtc, nextGroupIndex, capacity);
        return (newLeague, true);
    }
}

    // (ISystemClock for MissionPeriodCalculator.GetCurrentPeriod)

Algorithm `GetByStudentIdAsync(studentId)`:
1. Resolve `StudentXpProfile` (including `CurrentTier`) via `studentId`. If no profile → return sentinel `(Bronze, 0, 0, 0)`.
2. Compute current week via `MissionPeriodCalculator.GetCurrentPeriod(MissionType.Weekly, _clock.UtcNow)` → `(periodKey, startUtc, endUtc)`.
3. Look up `LeagueMembership` for `(profile.Id, periodKey)` via `GetActiveLeagueMembershipAsync`. If found → skip to step 6.
4. **Lazy placement:**
   - `var cohorts = await _repo.GetCohortsForPeriodAndTierAsync(periodKey, profile.CurrentTier, ct)`.
   - `var counts = await _repo.GetCohortParticipantCountsAsync(periodKey, profile.CurrentTier, ct)`.
   - `var (league, createdNew) = LeaguePlacementService.FindOrCreateCohort(profile.CurrentTier, periodKey, startUtc, endUtc, cohorts, counts, _options.Value.CohortSize)`.
   - If `createdNew`: `await _repo.AddLeagueAsync(league, ct)`.
   - Compute `joinOrder = (counts.ContainsKey(league.Id) ? counts[league.Id] : 0) + 1`.
   - `var membership = LeagueMembership.Create(league, profile, joinOrder, _clock.UtcNow, periodKey)`.
   - `await _repo.AddLeagueMembershipAsync(membership, ct)`.
   - Save. **Catch `DbUpdateException`** narrowed to `UX_LeagueMemberships_StudentXpProfileId_PeriodKey` violation → concurrent placement race tie-break → re-fetch membership.
5. Re-read membership from DB (after save or after catch).
6. Compute rank: `1 + count of memberships in same LeagueId WHERE (WeeklyXp > caller.WeeklyXp) OR (WeeklyXp == caller.WeeklyXp AND JoinedAtUtc < caller.JoinedAtUtc)`.
7. Read cohort size: `count of memberships WHERE LeagueId = membership.LeagueId`.
8. Return `new StudentLeagueSnapshot((LeagueTierDto)(int)profile.CurrentTier, rank, membership.WeeklyXp, cohortSize)`.
