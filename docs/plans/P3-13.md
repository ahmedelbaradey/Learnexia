### Batch 3 — PARALLEL — `backend-feature` agent (two threads)

**Depends on:** Batch 1 (both threads) AND Batch 2 complete.

#### Batch 3a — BE-4 (StudentProfileEngine + unit tests)

**Files (NEW):**
- `Learning.Domain/Services/StudentSignals.cs` — record: `IReadOnlyList<(QuestionType, int correct, int total)> AnswersByType`, `IReadOnlyList<(int skillId, int wrongCount)> SkillErrorCounts`, `IReadOnlyList<(int minuteBucket, double accuracy)> SessionAccuracyBuckets`, `double OverallAccuracy`, `int TotalAnswers`.
- `Learning.Domain/Services/DerivedProfile.cs` — record: `IReadOnlyDictionary<string, double> QuestionTypeAffinity`, `IReadOnlyList<int> RecurringErrorSkillIds`, `int? AttentionSpanMinutes`, `ExplanationStyle PreferredExplanationStyle`, `int DataPointCount`.
- `Learning.Domain/Services/StudentProfileEngine.cs` — pure static class, `Derive(StudentSignals signals, StudentProfileOptions options) → DerivedProfile`. Four private derivation methods:
  - `DeriveQuestionTypeAffinity`: per-type success rate; "affinity" = types above overall rate with min-sample guard (`options.MinSamplePerQuestionType`).
  - `DeriveRecurringErrorClusters`: skills where `wrongCount >= options.RecurringErrorThreshold`.
  - `DeriveAttentionSpan`: find minute-bucket where accuracy drops below session-start accuracy by `options.AccuracyDropThreshold`; returns null if insufficient data (cold-start safe). **Comment in code: "v1 proxy from Attempt/StudentAnswer timestamps; enrich from P5-03 (not yet built) when available."**
  - `DeriveExplanationStyle`: conservative heuristic from affinity + hint behavior (documented in code as a heuristic, not a measurement); `Standard` default when data is insufficient; returns `Standard` on cold-start path. **Comment in code: "Speculative derivation — confirm ExplanationStyle enum values match P3-03 prompt builder before enabling this feature."**
  - Cold-start path: if `signals.TotalAnswers < options.ColdStartDataPointThreshold`, return neutral default `DerivedProfile` (empty affinity/clusters, null attention span, `PreferredExplanationStyle = Standard`).
- `tests/Modules.Learning.UnitTests/StudentProfileEngineTests.cs` — 10+ cases: cold-start → neutral defaults; strong MCQ accuracy → MCQ affinity; weak FillInBlank accuracy → not in affinity; recurring errors on 3 answers for same skill → appears in clusters; recurring errors below threshold → not in clusters; accuracy drop in later minute-bucket → attention span detected; attention span with no data → null; explanation style standard on cold-start; explanation style shifts on affinity+hint signal; reproducibility (same signals twice = same output).

**PATTERN CAUTION (rule 8 — HIGHEST RISK IN THE CLUSTER):** four derivations invite Strategy/Visitor/Pipeline. Default is four private methods in one plain static engine. **If BE-4 implementer reaches for any abstraction pattern, STOP and ask the lead explicitly before proceeding.**

### Batch 7 — SEQUENTIAL — `security-auditor` agent — MANDATORY

**Sensitivity: HIGH — this profiles a minor (child behavioral data). Critical/High findings BLOCK the reviewer gate.**

Mandatory audit focus (from the brief — verbatim):
- **IDOR:** `GET /api/Learning/Profile` returns only the JWT child's data; `studentId` is NEVER from route, query-string, or request body — it is always `ICurrentUserService.UserId`.
- **Data minimization:** `StudentLearningProfileDto` exposes ONLY the four AC1 attributes + confidence indicators. No raw answer data, no timestamps of individual answers, no raw session logs in the response.
- **Purpose limitation:** profile is used for personalization (prompts/adaptivity). Confirm no endpoint exposes one child's derived behavioral attributes to another child or to a role other than the owning student.
- **Transparency (AC5):** the profile inspection endpoint is accessible to the owning child (self-only, JWT-scoped).
- **No PII leakage:** no `ex.Message` or exception stack trace in any response.
- **Recompute job isolation:** the sweep job cannot cross-pollinate one student's profile with another's data (confirm the job queries are student-scoped).
- **Grade transition:** confirm the profile entity is not reset on grade change (no grade filter on `StudentLearningProfile` queries that could hide historical data).

**Gate:** **Critical/High findings BLOCK.** Medium findings documented and must be acknowledged by the lead. Low/Info noted. Reviewer gate opens ONLY after security-auditor PASS.
