## Plan summary

P4-11 is the **last Phase-3 backend story**, closing the BE4 Daily Habit System. It layers three mechanics onto the existing Gamification module in a single PR: (a) **streak freeze** — a consumable integer inventory (`FreezeBalance`) earned at 7-day streak milestones, auto-consumed by `StreakSweepJob` before a break would fire; (b) **timed events** — a new `TimedEvent` catalog table with `StartUtc`/`EndUtc`/`Multiplier`, read by a new `IXpBoostCalculator` service injected into five existing XP-awarding handlers (handler-side calculator, not a new MediatR pipeline behaviour — per lead lock Q7=B + CLAUDE.md rule 8), with a `TimedEventSweepJob` toggling `IsAnnouncedActive` every 2 minutes; and (c) **weekly challenges** — 2-3 new `CHALLENGE_*` rows appended to the existing `MissionSeeder` using the existing `MissionType.Weekly` cadence (Q3=reuse, no new enum or table). All three mechanics are extensions of existing engines; no new module, no new DbContext, no FE work in this story.
