### How to gate the Python work (the `reviewer` agent is .NET-oriented)

The `reviewer` subagent reviews against CONVENTIONS.md and runs .NET build/tests — it is not equipped to deeply review Python idioms. **Recommended Python gating (three layers):**
- **(a) Automated, authoritative:** the general-purpose agent's own `pytest` suite green in CI — PY-6 (Arabic OCR smoke against the mock), PY-8 (diacritics e2e), and the **PY-9 Testcontainers contract test** (atomic-claim race + MinIO round-trip). This is the load-bearing proof of the outbox handshake and its assertions are language-agnostic.
- **(b) Contract-level reviewer check:** the reviewer verifies the **cross-process contract** from the .NET side — the claim SQL, `ResultJson` shape (`{artifact_key, chapters[], parse_status, diagnostics}`), `Status`/`JobType` strings, and bucket name match exactly what BE-7/api-tester expect. The contract, not the Python internals, is what the reviewer gates.
- **(c) Focused human/lead review pass:** because this is the first Python in the repo, recommend the **lead** (or a focused general-purpose review pass) eyeballs `pyproject.toml` (pinned deps + MIT-license confirmation), the `Dockerfile`, secret handling (env-only), and the compose/minio-setup diff — items the .NET reviewer won't catch.
- The reviewer's PASS for BL-02 should explicitly cite "pytest + contract test green (per general-purpose report)" rather than re-deriving Python correctness.

### security-auditor — REQUIRED (recommendation: YES)

Security-sensitive surface; the auditor **should run** (Batch 4), covering:
- **External credentials:** Azure DI key, Claude key, Postgres conn string, MinIO creds — all env/secret-store, never source; no key logging. Compose uses `${VAR}` references only.
- **Untrusted file handling:** the worker OCRs admin-uploaded but still-untrusted PDFs/images/DOCX; confirm no shell-out on `object_key`/file contents, path-safety on `object_key` used as a MinIO key and when deriving the artifact key (no traversal), size/type bounds honored.
- **Outbox payload trust:** the worker trusts `PayloadJson` from the outbox — confirm BL-01 constrains it to `{object_key, content_type}` and the worker doesn't interpret it as a path/command.
- **Admin authz:** `POST /{id}/reparse` `[Authorize(Roles="Admin,SuperAdmin")]`; no IDOR on `{id}`.
- **AI prompt:** Claude VLM caption prompt over admin-uploaded images — confirm no prompt-injection escalation path (lower risk than student input, but verify).
Critical/High findings block the reviewer gate.
