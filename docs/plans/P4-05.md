## Acceptance criteria (verbatim from story)

1. **AC1** — Badges are awarded by rule (e.g., skill mastered, N-day streak, quiz master) evaluated on relevant events.
2. **AC2** — Earning a badge writes a `StudentBadge` record and triggers a reward popup.
3. **AC3** — A badge is awarded at most once per its condition (no duplicates).
4. **AC4** — Earned and locked badges are visible in a badge collection screen.

**`BadgePredicateEvaluator.cs`** at `Gamification.Domain/Services/`:

```csharp
public static class BadgePredicateEvaluator
{
    public static IReadOnlyList<int> Evaluate(
        BadgeEvaluationContext ctx,
        IReadOnlyList<BadgeDefinition> catalog,
        IReadOnlySet<int> alreadyEarnedBadgeDefinitionIds)
    {
        var matches = new List<int>();
        foreach (var def in catalog)
        {
            if (alreadyEarnedBadgeDefinitionIds.Contains(def.Id)) continue;
            if (def.TriggerType != ctx.Source) continue;
            bool eligible = ctx.Source switch
            {
                BadgeTriggerType.FirstLesson     => true,   // not-in-earned-set check above suffices
                BadgeTriggerType.StreakThreshold => (ctx.StreakValue ?? 0) >= (def.Threshold ?? int.MaxValue),

                _ => false,
            };
            if (eligible) matches.Add(def.Id);
        }
        return matches;
    }
}
```
