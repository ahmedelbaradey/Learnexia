##### `backend/src/Modules/Learning/Learnexia.Modules.Learning.Application/Features/Dashboard/Queries/GetDashboard/GetDashboardQueryHandler.cs` (NEW)

**Handler logic (complete spec):**

Inject: `ILearningRepositoryManager _repository`, `ICurrentUserService _currentUser`, `ILoggerManager _logger`, `IStringLocalizer<SharedResources> _localizer`.

Implement `IQueryHandler<GetDashboardQuery, BaseResponse<DashboardDto>>`, inherit `BaseResponseHandler`.

```
Step 1 — Auth guard
  if (_currentUser.UserId is not { } studentId)
      return Unauthorized<DashboardDto>(_localizer[SharedResourcesKey.Unauthorized]);

Step 2 — Resolve primary subject
  var recentSubjectId = await _repository.Learning
      .GetMostRecentActivitySubjectIdAsync(studentId, ct);   // Q11 new method

  int? primarySubjectId = recentSubjectId;

  if (primarySubjectId is null)
  {
      // No attempts — fall back to Grade 1 Math (Q3.bis)
      primarySubjectId = await _repository.Learning
          .GetByCondition<Subject>(
              s => s.Name == "Math" && s.Grade.Number == 1, false)
          .Select(s => (int?)s.Id)
          .FirstOrDefaultAsync(ct);
      // If primarySubjectId is still null (extreme — seeder didn't run), Continue = null below.
  }

Step 3 — Resolve Continue target
  ContinueTargetDto? continueTarget = null;

  if (primarySubjectId is not null)
  {
      // Try primary subject first; if no Available lesson found, iterate others.
      // Deterministic subject order for fallback: Math, Science, Arabic, English.
      var subjectIdsToTry = new List<int> { primarySubjectId.Value };

      // Load all grade-1 subjects for the cross-subject fallback — one extra query.
      // We only need to append the OTHER subjects; the handler uses Name ordering.
      var grade1SubjectNames = new[] { "Math", "Science", "Arabic", "English" };

      var grade1Subjects = await _repository.Learning
          .GetByCondition<Subject>(
              s => s.Grade.Number == 1, false)
          .Include(s => s.Grade)
          .OrderBy(s => Array.IndexOf(grade1SubjectNames, s.Name) < 0
                        ? 999 : Array.IndexOf(grade1SubjectNames, s.Name))
          .ToListAsync(ct);

      // Append remaining subjects (not already in list), in deterministic order.
      subjectIdsToTry.AddRange(
          grade1Subjects
              .Where(s => s.Id != primarySubjectId.Value)
              .Select(s => s.Id));

      foreach (var subjectId in subjectIdsToTry)
      {
          continueTarget = await TryResolveContinueForSubjectAsync(
              studentId, subjectId, grade1Subjects, ct);
          if (continueTarget is not null) break;
      }
  }

Step 4 — Assemble DashboardDto
  var dto = new DashboardDto(
      Xp: 0,                    // TODO P4-02
      Streak: 0,                // TODO P4-03
      DailyMission: null,       // TODO P4-06
      LeaguePreview: null,      // TODO P4-07
      Continue: continueTarget
  );

Step 5 — Return
  return Success(dto);
```

**Private helper `TryResolveContinueForSubjectAsync`:**
1. Bulk-fetch the 5 engine inputs for `subjectId` (mirror `GetSubjectSkillTreeQueryHandler` lines 77–96 exactly — same 5 calls to `_repository.Learning`).
2. Build `skillsById` from `concepts.SelectMany(c => c.Skills)` — query `Concept` with Include chains or use existing `GetByCondition<Concept>` with `Include(c => c.Skills)`.
3. Call `LearningPathEngine.ComputeStates(nodes, edges, masteryBySkillId, completedLessonIds, lessons, skillsById)`.
4. Pick the first lesson where `unlockStates[l.Id].NodeState == NodeState.Available`, ordered by `l.SequenceOrder ASC` then `l.Id ASC`.
5. If no Available lesson → return `null`.
6. Project to `ContinueTargetDto`:
   - Load subject name + unit name from the pre-fetched entity graph (the `lessons` list carries `UnitId`; join to loaded `grade1Subjects` or fetch the `Unit` with `Include(u => u.Subject)` — one lookup).
   - `SkillId = lesson.SkillId` (nullable).
   - `SkillName = lesson.SkillId.HasValue && skillsById.TryGetValue(lesson.SkillId.Value, out var sk) ? sk.Name : null`.
   - `NodeState = NodeState.Available` (always).

**Error handling (whole Handle body):**
```csharp
catch (Exception ex)
{
    _logger.LogError(ex, "Error in GetDashboardQuery for student {StudentId}", studentId);
    return ServerError<DashboardDto>();   // NO ex.Message — mirror P2-04/P2-05/P2-07/P2-08 pattern
}
```

**Localization:** no new keys required. `SharedResourcesKey.Unauthorized` is reused in the auth guard. If the Grade-1 Math subject is not found (extreme — seeder not run), return `Success` with `Continue=null` rather than a localized error (per Q8: empty state is valid).

public async Task<int?> GetMostRecentActivitySubjectIdAsync(
    int studentId, CancellationToken ct = default)
    => await RepositoryContext.Attempts
        .AsNoTracking()
        .Where(a => a.StudentId == studentId)
        .OrderByDescending(a => a.StartedAt)
