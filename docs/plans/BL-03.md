## security-auditor scope (REQUIRED)
1. **Decision-E invariant (primary):** prove the ONLY code path writing `KnowledgeEdge` is `ApproveKGSuggestionCommand` → `IKnowledgeEdgeWriter`, and that path always runs `SkillGraphValidator.AssertAcyclic` first (no bypass; `EdgeInferenceAdvanceService` and BE-3 never touch `KnowledgeEdge`).
2. **Cross-module write authz:** all suggestion-mgmt + `/Build` endpoints `AdminOnly`; query endpoints student-readable WITH the inactive-skill filter (no hidden-skill disclosure via traversal).
3. **LLM/prompt-injection:** untrusted curriculum text cannot inject arbitrary published edges — the approval gate + acyclic check + admin review is the mitigation; Python output is untrusted, so clamp Strength server-side (mirror `ClampConfidence`).
4. **Graph-traversal DoS:** remediation transitive walk is depth-bounded (default 3, configurable) + cycle-guarded; `/Build` rate-limited / system-gated.
5. **Secrets:** inference-service URL/key in the secret store, never in source (ADR-0004 posture).

## Lockstep item — the `infer_edges` ResultJson cross-process contract (BL-05 divergence lesson)
Define the EXACT field names ONCE in Batch 1, written into `docs/briefs/BL-03.md` + `docs/dev/HANDOFF.md`, and have BOTH the .NET `EdgeInferenceAdvanceService` deserializer (BE-3) and the Python `infer_edges` writer (PY-1) build to it. **A contract test is mandatory** (PY-4 asserts the JSON shape; api-tester feeds the same fixture through `EdgeInferenceAdvanceService`).

Proposed `ResultJson` shape (snake_case on the wire, mirroring the existing `parse`/`ingest` ResultJson convention):
```json
{
  "inference_model": "lightrag-v1-mock",
  "edges": [
    {
      "source_skill_key": "math.grade4.division.long-division",
      "target_skill_key": "math.grade4.fractions.add-unlike-denominators",
      "relationship_type": "Prerequisite",
      "strength": 0.82,
      "confidence": 0.91
    }
  ]
}
```
- `relationship_type` is `"Prerequisite" | "Related"` (string on the wire, consistent with the `JobType`/`Status` string contract); .NET maps to the `CurriculumRelationshipType` enum.
- Python emits by **SkillKey** (stable identity across versions, Decision C); `EdgeInferenceAdvanceService` resolves SkillKey → `KnowledgeNode.Id` via `IKnowledgeNodeReader` before writing `KGSuggestion` (which stores plain int ids). Unresolved SkillKeys are dropped + logged (fail-soft, like below-threshold ingest items).
- `.NET re-clamps strength + confidence to [0,1]` — never trust the Python value (mirror `ClampConfidence`).

## Proposed seam signatures (Batch 1 freezes these)
```csharp
namespace Learnexia.Shared.Contracts.Learning;

// WRITE seam — the SINGLE cross-module publish path (Decision E chokepoint).
// Implemented in learning Infrastructure; reuses the AddKnowledgeEdgeCommandHandler guard chain.
public interface IKnowledgeEdgeWriter
{
    Task<EdgePublishResult> PublishApprovedEdgeAsync(
        int sourceNodeId,
        int targetNodeId,
        int relationshipType,   // maps to learning EdgeRelationshipType
        decimal strength,
        CancellationToken ct = default);
}

public sealed record EdgePublishResult(
    bool Published,
    bool Duplicate,       // edge already existed (hand-authored or prior approval) → treat as success/no-op
    bool Cycle,           // acyclic guard rejected → domain error, no commit
    bool CrossLanguage,   // cross-language guard rejected → domain error, no commit
    int? EdgeId);

// READ seam — lets curriculum resolve/validate learning nodes for BE-3 without a project ref.
public interface IKnowledgeNodeReader
{
    // For BuildKnowledgeGraphSuggestionsCommand: nodes to feed inference.
    Task<IReadOnlyList<KnowledgeNodeDto>> GetNodesForSubjectAsync(
        int subjectCode, int gradeId, CancellationToken ct = default);

    // For EdgeInferenceAdvanceService: resolve Python's SkillKeys → node ids before writing KGSuggestion.
    Task<IReadOnlyList<KnowledgeNodeDto>> GetNodesBySkillKeysAsync(
        IEnumerable<string> skillKeys, CancellationToken ct = default);
}

public sealed record KnowledgeNodeDto(
    int NodeId,
    string SkillKey,
    string Name,
    int NodeType,
    int SubjectCode,
    int GradeId,
    int Difficulty);
```
Notes: both interfaces live in `Shared.Contracts.Learning` and are implemented in `Learning.Infrastructure` (mirroring `PedagogicalTreeWriterAdapter`), registered `AddScoped` in Learning.Infrastructure `DependencyInjection.cs`. `curriculum` consumes the interfaces only — **no project reference**. The writer keeps acyclic + cross-language enforcement INSIDE `learning` (where the live edge set is), giving the security-auditor one auditable chokepoint. Final field/method names are the implementer's to refine, but the **shape is frozen at Gate 1** so the curriculum caller and learning impl build to the same contract.
