## Critical reuse mandate (do NOT rebuild)

The following are **built and in `learning`** (P2-11, audited 2026-06-07). BL-03 must NOT recreate any of them:

- `KnowledgeNode`, `KnowledgeEdge` entities + EF configs + `AddSkillGraphTables` migration
- `SkillGraphValidator.AssertAcyclic` (DFS cycle check)
- `KnowledgeGraphController` with `GetPrerequisitesOf` + `GetUnlockedBy`
- `AddKnowledgeEdgeCommand` (edge authoring seam)
- `LearningPathEngine` (consumes edges)

BL-03's scope is **strictly the delta**: (1) automated graph build from BL-05 structured curriculum via LightRAG inference, (2) populate `Related` edges + meaningful strengths, (3) `GetRelatedConcepts` query (if missing), (4) remediation traversal depth extension, (5) optional edge provenance fields.

### Batch 5 — PARALLEL — `api-tester` + `security-auditor`

**Agent:** `api-tester` + `security-auditor` (parallel)
**Depends on:** Batch 4 complete (.NET) + Python service running or mocked.

**`api-tester` validations (against mocked inference client + seeded P2-11 graph):**
1. `POST /Build` (admin, mocked inference returns stubbed edges) → nodes/edges with strengths persisted; `SkillGraphValidator` passes.
2. Inferred edge that would create a cycle → rejected by `SkillGraphValidator`; 422 envelope; graph NOT corrupted.
3. Re-build (second `POST /Build`) → no duplicate edges (idempotent, insert-or-ignore).
4. `GET /Prerequisites/{nodeId}` for a known seeded chain (e.g. Fractions → Division) → correct result (baseline from P2-11).
5. `GET /UnlockedBy/{nodeId}` → correct result (baseline from P2-11).
6. `GET /RelatedConcepts/{nodeId}` → correct `Related`-edge nodes returned.
7. `GET /RemediationPath/{nodeId}` → upstream prerequisite(s) returned per Q3 depth.
8. `POST /Build` by non-admin → 403.
9. `Successed` key in response envelope.

**`security-auditor` checklist (REQUIRED — LightRAG/AI + writes to the most critical platform asset):**
- LightRAG / inference-service credentials in secret manager; NOT in source.
- Auto-build is admin/system-only; cannot be triggered by a student or unauthenticated request.
- Prompt-injection: curriculum node names fed to LightRAG/LLM cannot inject arbitrary edges without passing `SkillGraphValidator` cycle check — confirm this is the only guard and it is always called.
- `IsAutoBuild = false` (hand-authored) edges are NOT overwritten by auto-build (insert-or-ignore semantics, not upsert-and-overwrite).
- P2-11 hand-seeded curated edges survive a `POST /Build` call (assert in api-tester test #3 or a dedicated test).
- Neo4j migration path: no proprietary relational-only constructs that would block a future Neo4j migration.

Critical/High findings block the gate.
