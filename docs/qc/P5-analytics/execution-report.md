## Findings

### FINDING DEL-F01 — Recipient semantics (Severity: LOW)
**Story:** P5-04 AC3 "only linked parents notified"
**Observed:** `Notification.RecipientExternalUserId = childId` (not parentId)
**Detail:** The `WeeklyRecapReadyIntegrationEventHandler` resolves the parent via `FindParentForChildAsync` for preference gating, but the `NudgeMessage.RecipientChildUserId` is set to `childId`. The dispatcher persists `RecipientExternalUserId = childId`. This is consistent with all 11 re-engagement handlers in the codebase — they are all child-keyed re-engagement rows.
**Functional impact:** AC3 is satisfied functionally — cross-family isolation test (DEL-INT-03) passes with zero leakage. The FE parent app must read via the parent-child linkage (reads child's notification inbox, not parent's own inbox).
**Action:** Flagged for lead review. No feature code change recommended unless the FE reading model requires parent-id keyed notifications.

## Blockers

### BLOCKED DEL-INT-06 — pushsender-fault-mode
`TestPushSenderImpl` does not support a fault mode. Push-failure inbox isolation is verified by code review and the NudgeDispatcher design (inbox written before push). Unblock: add `SetFaultMode(bool)` to `TestPushSenderImpl`.

## Pre-existing harness notes

### Npgsql legacy timestamp behavior
`AppContext.SetSwitch("Npgsql.EnableLegacyTimestampBehavior", true)` causes `timestamp without time zone` columns to be returned in local time. Two assertions in P5-01 were adjusted (4h window for GeneratedAtUtc; .Date comparison for WeekStartUtc). These are test-level adaptations; no feature code was changed.

### Pre-existing P8_02/P8_03 compile errors
The project has 6 pre-existing compile errors in `P8_02_BilingualContent_Tests.cs` and `P8_03_ServeInLearningLanguage_Tests.cs` (`Domain` namespace not found). These are unrelated to this QC run and existed before these tests were added. The new P5 test files compile without errors.
