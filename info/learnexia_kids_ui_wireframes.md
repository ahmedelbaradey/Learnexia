Design a simple, gamified, highly visual learning experience inspired by Duolingo-style engagement but adapted for AI-powered learning.

# 🧠 Design Principles

## 1. Simplicity First
- big buttons
- minimal text
- visual learning

## 2. Instant Feedback
- XP immediately
- animations

## 3. Emotional Rewards
- badges
- streaks
- celebration screens

## 4. Low Cognitive Load
- one task per screen

## 5. Gamification Everywhere
- every action = reward
