## AI Model Strategy Discussion

### Key Insight
No single AI model is optimal for all tasks.

### Proposed Hybrid Strategy:
- Lightweight models → simple Q&A
- Advanced models → reasoning + deep learning
- Multi-provider abstraction layer

### Key Principle:
- Avoid dependency on a single AI provider
- Build modular model routing system

---

## Fine-Tuning Strategy

Recommended approach:
- Use Retrieval Augmented Generation (RAG) as primary system
- Fine-tuning only for:
  - Teaching style consistency
  - Persona adaptation (teacher-like behavior)

RAG preferred due to:
- Fast updates
- Easy content injection
- Scalability

---

## Recommended Tech Stack

### Backend
- .NET (Clean Architecture) or Node.js (NestJS)
- Microservices-based design
- API Gateway for orchestration

### AI Layer
- External LLM providers via abstraction layer
- RAG pipeline for knowledge ingestion
- Vector database (for embeddings + retrieval)

### Data Layer
- PostgreSQL (core relational data)
- Vector DB (for semantic search)
- Redis (caching + session memory)

### Media Layer
- Audio generation service (TTS engine integration)
- Video rendering pipeline (template-based MVP → advanced AI video later)

### Frontend
- React / Next.js
- Role-based dashboards (Student / Teacher / Parent)
- Real-time updates (WebSockets / SignalR)
