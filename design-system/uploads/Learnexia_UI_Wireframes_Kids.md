# 🧠 UX Principles

# Always

- Large touch targets
- Minimal text
- Bright visual feedback
- One action per screen
- Fast navigation

---

# Never

- Complex menus
- Dense paragraphs
- Too many buttons
- Small text

---

# 🎮 Gamification Integration

Every screen should reinforce:
- progress
- rewards
- motivation
- achievement

---
