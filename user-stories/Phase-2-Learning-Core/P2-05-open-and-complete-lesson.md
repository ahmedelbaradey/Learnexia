# Open and complete a lesson

- **Project:** Learnexia
- **Sprint / Phase:** Phase 2 — Learning Core (Week 3–4)
- **Epic:** Learning Module
- **Issue type:** Story
- **Story Points:** 5 — lesson assembly endpoint + lesson screen; AI explanation integrated later in P3.
- **Labels:** `learning`, `backend`, `frontend`
- **Requirements:** FR-LR-4

## Description
As a student, I want to open a lesson that shows an explanation, a visual example, and a quick check, so that I can learn a concept and immediately confirm I understood it.

## Acceptance Criteria
- The lesson assembly endpoint returns the explanation, a visual example, and an embedded quick-check question.
- The lesson screen shows the AI tutor bubble, visual area, and hearts/streak display.
- Completing the quick check records an attempt and marks lesson progress.
- In Phase 2, the explanation may use seeded/static content; the AI-generated explanation is wired in Phase 3.
