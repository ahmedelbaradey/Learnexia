# See the home dashboard

- **Project:** Learnexia
- **Sprint / Phase:** Phase 2 — Learning Core (Week 3–4)
- **Epic:** Learning Screens
- **Issue type:** Story
- **Story Points:** 3 — aggregation of several widgets; some (league/mission) show placeholders until P4.
- **Labels:** `frontend`, `learning`
- **Requirements:** FR-LR, G1

## Description
As a student, I want a home dashboard showing my progress and next step, so that I can jump straight back into learning each day.

## Acceptance Criteria
- The dashboard shows: XP, streak, daily mission, a "continue" entry point, and a league preview.
- Tapping "continue" opens the next unlocked lesson from the learning path.
- Widgets that depend on Phase 4 (mission, league) render gracefully as placeholders until gamification is live.
- Renders in Arabic (RTL) and English.
