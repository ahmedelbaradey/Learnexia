# Pass localization & RTL review

- **Project:** Learnexia
- **Sprint / Phase:** Phase 6 — Stabilization (Week 9)
- **Epic:** QA & Stabilization
- **Issue type:** Story
- **Story Points:** 3 — systematic pass across all screens in Arabic RTL + English.
- **Labels:** `qa`, `localization`
- **Requirements:** NFR-5

## Description
As an Arabic-speaking student, I want every screen to look and read correctly in Arabic, so that the experience feels native, not bolted-on.

## Acceptance Criteria
- All screens are reviewed in Arabic (RTL) and English; layout, mirroring, and fonts (Cairo/Tajawal/Poppins) are correct.
- Text is not clipped, overlapping, or left-aligned where it should be right-aligned.
- Numbers, dates, and mixed-direction content render correctly.
- Issues found are logged and fixed or scheduled with severity.

## Notes
- Covers Q1.5. Arabic-first is a core differentiator (BRD §1).
