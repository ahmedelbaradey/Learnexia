# Detect and rank weak areas

- **Project:** Learnexia
- **Sprint / Phase:** Phase 5 — Parent + Analytics (Week 8)
- **Epic:** Parent & Analytics
- **Issue type:** Story
- **Story Points:** 3 — derive weak areas + severity from mastery/answer data.
- **Labels:** `parent`, `analytics`, `backend`
- **Requirements:** FR-PA-2

## Description
As a parent, I want to see my child's weak areas with a sense of how serious each is, so that I can focus support where it matters most.

## Acceptance Criteria
- Weak areas are derived from mastery data (<50% = needs remediation) and recent answer accuracy.
- Each weak area carries a severity indicator.
- Weak areas surface in the weekly report and the parent dashboard.
- Resolved/improved areas drop off the list automatically.
