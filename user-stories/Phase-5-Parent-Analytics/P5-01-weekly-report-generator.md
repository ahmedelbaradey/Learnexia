# Generate a weekly student report

- **Project:** Learnexia
- **Sprint / Phase:** Phase 5 — Parent + Analytics (Week 8)
- **Epic:** Parent & Analytics
- **Issue type:** Story
- **Story Points:** 5 — aggregation across XP, mastery, and weak areas into a scheduled report.
- **Labels:** `parent`, `analytics`, `backend`
- **Requirements:** FR-PA-1

## Description
As a parent, I want a weekly report on my child, so that I can see measurable progress and know how to help.

## Acceptance Criteria
- A weekly report is generated per student covering: XP earned, skills improved, weak areas, and recommendations.
- The report is generated by a scheduled background job for the prior week.
- A parent can only see reports for their linked children.
- Given a week with no activity, then the report states that clearly rather than showing empty/garbled data.
